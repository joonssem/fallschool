# 01. Fall Guys 게임성 분석과 학교 현장 적용 탐색

- 문서 상태: 탐색 1차

- 관련 문서: [README](../README.md), [02. 라운드 카탈로그](02-라운드-카탈로그.md)

## 0. 확정된 전제

| 항목 | 결정 |
|---|---|
| 대상 학년 | 초등 고학년(5~6학년) |
| 경쟁·협동 비중 | 혼합형: 개인 도전 + 모둠 협동 + 학급 공동 목표 |
| 문서 관리 | `docs/` 폴더에 단계별 Markdown 파일로 저장 |

### 고학년 대상일 때 고려할 점

- 규칙 이해력과 전략적 사고가 충분하므로 **숨겨진 규칙을 추론하는 라운드**를 적극 활용할 수 있다.
- 또래 비교와 서열에 민감한 시기이므로 **개인 순위 공개는 최소화**하고 모둠·학급 성취를 강조한다.
- 게임 경험 편차가 크다. 조작 실력이 결과를 좌우하지 않도록 **관찰·추론·협력 비중**을 높인다.
- 과학(용액, 전기, 태양계, 인체 등), 사회(역사), 수학(분수·비율·도형) 등 체험형으로 만들기 좋은 단원이 많다.

## 1. Fall Guys 재미의 핵심 요소

> 원작의 실제 수치(인원, 라운드 수·시간, 라운드 종류, 크리에이티브)는 [07. 원작 사실 확인](07-원작-사실-확인.md) 참고 (2026-09-29 웹 조사).

| 요소 | 내용 | 왜 재미있는가 |
|---|---|---|
| 아주 단순한 조작 | 이동, 점프, 다이브, 잡기 | 누구나 10초 안에 익힌다 |
| 흐물흐물한 물리 캐릭터 | 젤리빈 캐릭터가 부딪히고 넘어지고 굴러감 | **실패가 창피하지 않고 웃기다** — 가장 중요한 요소 |
| 쇼 구조 | 여러 라운드를 연속 진행하며 인원이 점점 줄어듦 | 긴장이 쌓이고 "한 판만 더"를 만든다 |
| 라운드 조합이 매번 다름 | 레이스, 생존, 논리, 팀, 결승 라운드를 섞음 | 예측할 수 없어 매번 새롭다 |
| 숨겨진 정보 | 가짜 문, 보이지 않는 발판 | 다른 사람의 실패를 보고 길을 알아낸다 — 관찰하며 배움 |
| 많은 인원의 혼돈 | 수십 명이 한 공간에서 동시에 플레이 | 매번 다른 상황과 웃긴 장면이 저절로 생긴다 |
| 짧은 라운드 | 라운드 1~5분, 쇼 전체 15~20분 | 부담 없이 반복할 수 있다 |
| 밝은 화면과 소리 | 파스텔 색, 경쾌한 음악, 과장된 효과음 | 위협적이지 않은 분위기 |
| 꾸미기와 보상 | 코스튬, 왕관 | 개성을 드러내고 성취를 보여 준다 |
| 창작 모드 | 이용자가 직접 맵 제작 | 만드는 사람이 된다 |

> 라운드 이름과 세부 규칙은 기억에 따른 것으로, 시즌마다 바뀌었을 수 있다. 확정 전에 최신 정보를 따로 확인한다.

## 2. 학교 현장 적합성 평가

### 2.1 그대로 가져올 요소

- **단순 조작**: 학년이나 게임 실력과 관계없이 누구나 참여할 수 있다.
- **실패가 웃긴 분위기**: 틀려도 괜찮다는 학습 문화와 맞는다.
- **짧은 라운드**: 40분 수업 안에 "플레이 → 토론 → 다시 도전"을 넣을 수 있다.
- **숨겨진 정보와 관찰**: 가설을 세우고 확인하는 과학적 탐구 방식과 바로 연결된다. 교육적 가치가 가장 크다.

### 2.2 바꿔서 가져올 요소

| 원작 요소 | 문제점 | 바꾸는 방향 |
|---|---|---|
| 탈락 방식 | 탈락한 학생이 할 일 없이 기다리고, 늘 같은 학생이 먼저 탈락한다 | 체크포인트 복귀, 점수 누적제, 탈락 후 관찰자·힌트 제공자 역할 |
| 잡기 | 방해나 괴롭힘에 쓰일 수 있다 | 물건과 협동 운반에만 사용, 교사가 켜고 끌 수 있게 |
| 팀 라운드 | 무임승차하는 학생, 잘해도 팀 때문에 지는 좌절 | 역할을 나눠 모든 학생이 필요하게 설계 |
| 무작위 라운드 순서 | 수업 목표와 상관없이 진행된다 | 교사가 라운드 목록을 구성 (무작위 옵션은 유지) |
| 기억 라운드 | 퀴즈 게임처럼 되기 쉽다 | 개념 짝 맞추기를 공간 탐색으로 바꿈 |
| 많은 인원 | 학교 기기 성능과 네트워크 한계 | 학급 규모 20~30명, 모둠 단위 방 |
| 코스튬 보상 | 비교와 경쟁을 부추길 수 있다 | 협력·관찰·정확성으로 얻고, 비교 요소는 줄임 |

### 2.3 뺄 요소

- 최후의 1인만 남기는 방식 (왕관은 모둠·학급 공동 목표로 바꾼다)
- 결제, 시즌 패스, 로그인 기반 소셜 기능 (학생 개인정보 문제)
- 과도한 카메라 흔들림과 회전 (멀미)

### 2.4 장기적으로 가치가 가장 큰 요소

- **창작 모드 → 학생이 직접 맵을 만드는 수업**. 교과 원리를 장애물로 설계하는 활동은 곧 개념을 깊이 이해하는 활동이다.

## 3. Fall Guys에는 없고 학교에만 필요한 요소

- 교사용 제어판: 시작, 정지, 난이도, 팀 구성, 관전 화면
- 라운드가 끝난 뒤 되돌아보기: "무엇을 발견했나?" 1~3분
- 학습 기록 (개인정보는 최소한으로)
- 교실 환경 대응: 소리 없이도 플레이 가능, 1인 1기기와 모둠 1기기 모두 지원
- 로그인 없는 접속: 방 코드 + 별명

## 4. 혼합형(경쟁 + 협동) 구조 초안

원작의 "탈락 퍼널" 대신 **세 층의 목표**가 동시에 진행되는 쇼 구조를 기본으로 한다.

| 층 | 목표 | 보상·표시 방식 |
|---|---|---|
| 개인 | 자기 기록 갱신, 발견한 단서 수 | 본인에게만 보이는 개인 기록, 순위 전체 공개는 하지 않음 |
| 모둠(4명 내외) | 모둠 라운드 성공, 역할 수행 | 모둠 점수, 모둠 간 선의의 경쟁 |
| 학급 | 쇼 전체에서 학급 공동 게이지 채우기 | 학급 왕관 획득, 모두가 함께 축하 |

### 기본 쇼 흐름 예시 (40분 수업)

| 순서 | 라운드 | 성격 | 시간 |
|---|---|---|---|
| 1 | 워밍업 레이스 | 개인, 조작 익히기 | 3분 |
| 2 | 관찰·추론 라운드 | 개인 도전이지만 서로의 실패가 단서가 됨 | 4분 |
| — | 되돌아보기 | "어떤 규칙을 발견했나?" | 3분 |
| 3 | 모둠 협동 라운드 | 역할 분담 | 5분 |
| — | 되돌아보기 | 모둠별 전략 공유 | 3분 |
| 4 | 학급 결승 라운드 | 학급 전체 공동 목표 | 5분 |
| — | 정리 | 학습 개념 3문장 요약 | 5분 |

- 탈락 없음. 실패하면 체크포인트로 복귀하거나 **관찰자 역할**(단서 표시, 힌트 핑)로 전환해 계속 기여한다.
- 모둠 간 경쟁 점수는 속도만이 아니라 **정확성·협력·발견**을 함께 반영한다.
