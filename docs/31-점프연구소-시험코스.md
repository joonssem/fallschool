# 31. 점프 연구소 시험장: 게임성 시험 코스로 확장

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: 교사 보고("학생들이 쉬는 시간에 이 맵을 혼자서 진행하는 모습을 목격. 난이도를 올리고 다양한 장애물을 테스트하는 용도로 쓰자. 맵 길이도 늘려서 다양한 것을 넣어 보자"), [18](18-전체맵-게임성-분석.md) 1번, [19](19-게임성-반영-기준.md)
- 상태: **코드 구현·규칙 시험 완료. 난이도가 적절한지, 재미있는지, 장애물별 반응은 모두 미확인이다.** 교사 보고는 한 번의 관찰이며 모든 학생의 행동이 아니다.

## 목적과 원칙

- 이 맵은 **조작 연습 맵**(점프·달리기·다이브)이면서 이제 **장애물 시험 맵**이다. 학생이 혼자서 자주 하는 맵이라 어려운 장애물을 시험하기 좋다고 보고, 과학 퍼즐을 넣지 않고 이동의 재미를 유지한다([18](18-전체맵-게임성-분석.md) 개선 방향).
- 탈락 없음, 학생 간 밀치기 없음, 안전한 재시도는 그대로다. 떨어지면 구간 앞 체크포인트로 돌아오고 반복 낙하에는 기존 도움 점프가 켜진다. 움직이는 장애물은 모두 시간 `t`(방에서는 서버 시계)로 계산해 모든 화면에서 같다.
- **구간 이름에 난이도(★ ~ ★★★)를 붙였다.** 교사 화면의 구간별 낙하·막힘 기록으로 어느 장애물이 어려운지 볼 수 있다(기존 기능). 시험 맵으로서 이것이 가장 중요한 관찰 자료다.
- 1부(기존 구간)는 처음 하는 학생을 위해 기본 난이도를 거의 유지하고(아래), 2부(시험 구간)는 새 장애물과 높은 난이도로 만들었다. 시험장 입구에 "어려우면 쉬었다 가도 돼요" 안내를 넣었다.

## 시험·기록

- 시험: `tests/lab.mjs`(31건, `npm test`에 등록). 봇이 움직이는 구간은 통과 비율을 출력하고 최소 기준(≥1번 통과, 가능성 검사)만 검사한다. **통과 비율은 난이도 적절함의 증거가 아니다.**
- 공통 파일 변경: 없음. 얼음 바닥(`icy`)과 점프 패드의 `bounceSpeed` 옵션은 기존 기능을 쓴다. `src/level.js`만 수정했다.
- 구간 목록이 1부 8개에서 18개로 늘어 교사 화면의 구간 이름 표시가 길어진다 `[추론, 화면 미확인]`.

## docs/19 점검표 (시험 맵 관점)

| 항목 | 기록 |
|---|---|
| 핵심 재미 | 다양한 장애물을 몸으로 익히고 구간마다 다르게 통과하는 이동·숙련 |
| 의미 있는 선택 | 장애물마다 안전하게 가는 길과 도전 별 길(징검다리·패드 탑)이 있다. 사라지는 발판·맞바람은 어디에 설지·언제 갈지 고른다 |
| 즉시 결과 | 장애물이 눈에 보이게 작동하고 실패는 바로 체크포인트에서 다시 시작한다 |
| 다음 행동·성취 | 구간 통과마다 체크포인트 깃발, 도전 별. 별도 보상은 없다 |
| 구간 변화 | 구간마다 요구하는 조작이 다르다(정밀·거리·타이밍·밀림·미끄러움·높이·회피·바람) |
| 재시도 부담 | 체크포인트 14곳, 구간 길이 20~40m, 도움 점프. 시소 다리처럼 학생 간 영향을 받는 구간은 새로 넣지 않았다 |
| 기본 완주·선택 도전 | 모든 새 구간은 체크포인트 간 완주가 필요하다. 어려운 구간을 건너뛰는 길은 없다(조작 맵이므로). 별은 선택이다 |
| 친구와의 연결 | 새 구간에는 협동 요소가 없다. 같은 구간을 함께 도전하며 말로 도울 수 있다 `[기대, 미확인]` |
| 재체험 용도 | 시험 맵이다. 같은 학생의 반복은 숙련·시간 단축이다. 숨은 발판만 판마다 길이 다르다 |
| 근거·관찰 | 교사 보고 1건(혼자 진행하는 모습), 코드·시험(규칙·이동). 어려움·재미는 미확인 |

## 한계와 주의

- 긴 코스 후반의 숙련도 차이가 피로로 이어질 수 있다([18](18-전체맵-게임성-분석.md) 위험). 2부 입구에서 되돌아가 쉴 수 있게 체크포인트를 촘촘히 뒀지만 학생이 2부까지 오는지는 관찰이 필요하다.
- 컨베이어는 가장자리가 열려 있고, 맞바람은 학생을 뒤로 밀 수 있다. 터치 조작에서 불쾌한지 확인한다.
- 맞바람 구간은 바람이 느리게 할 뿐 막지는 않는다(직진 봇도 통과). ★★★ 표시가 적절한지는 관찰 후 조정한다.
- 해머 복도·얼음 판 등 한 구간의 낙하가 많으면 교사 화면에서 보고 구간 값을 바꾼다(주기·속도·폭이 코드 상수 한 곳에 있다).
- 이 맵은 코스 시드(`seed`)로 숨은 발판 길만 달라진다. 새 구간은 같은 판에서 모두 같다.

## 교실에서 볼 장면 ([12](12-교실-시험-관찰지.md)에 추가)

1. 학생이 어느 구간까지 가는가, 어느 구간에서 멈추거나 그만두는가(교사 화면의 구간별 낙하·막힘).
2. 구간마다 몇 번 만에 통과하는가, 같은 구간을 다시 도전하는가, 도전 별을 시도하는가.
3. 컨베이어·맞바람·얼음에서 "불편하다/재미있다"는 반응이 어느 쪽인가.
4. 쉬는 시간에 혼자 하던 학생이 새 구간에서 친구에게 알려 주거나 같이 도전하는가.
5. 처음 하는 학생이 1부의 난이도 상향(회전 막대·움직이는 발판)으로 막히는가.
