# 12. 교실 시험 관찰지

게임성 관찰은 [18. 전체 맵 분석](18-전체맵-게임성-분석.md)과 [19. 제작·수정 기준](19-게임성-반영-기준.md)에 연결한다. 맵을 수정한 뒤에는 결과를 보고 선택을 바꾸는 장면, 조작 없이 기다리는 시간, 같은 발판 왕복, 완주 후 자발적인 다른 방법 시도를 기록한다. “다시 하고 싶은 구간과 이유”, “재미가 줄었던 순간”도 묻는다. 첫 체험 만족과 재체험 의사는 별도로 기록하며 자동 시험을 재미의 근거로 쓰지 않는다.

- 작성일: 2026-10-01 (초안, 교사가 수업 흐름에 맞게 줄여 쓴다)
- 목적: 코드·시뮬레이션으로 확인하지 못한 항목을 교실에서 확인한다. 재미와 학습 효과는 이 시험으로만 판단할 수 있다.
- 근거 문서: [05 작업 기록](05-작업-기록.md), [08 전원 참여 모드](08-전원-참여-모드.md), [09 외부 평가 검토](09-외부-평가-검토.md), [10 과학 표현·협동 수정](10-과학표현-협동-수정.md)
- 원칙: 탈락 없음, 미완주 학생도 다음 라운드 참여. "재미있었다"는 반응과 "이해했다"는 증거를 따로 적는다.

## 1. 수업 전 (교사, 10분)

실제 기기·네트워크가 아니면 확인할 수 없는 것들이다. 결과를 표에 적는다.

| 확인 | 방법 | 결과 |
|---|---|---|
| 실제 Firebase 연결 | 교사 PC 1대 + iPad 여러 대로 방 만들기·참가 | |
| iPad 10세대(60Hz) fps | 학생용 기기에서 화면 우상단 fps 읽기 (21명 접속 상태) | |
| 안내판 글자 | iPad에서 직렬 문 현황판, 태양계 문 앞 질문, 안내판이 읽히는지 (20~24px로 줄어든 안내판 다수) | |
| 교사 패널 | 학생이 접속한 상태에서 학생 목록, 맵 바꾸기 목록(10개 이상) | |
| 직렬 문 마지막 무리 | 늦게 도착하거나 다시 접속한 화면의 상태가 다른 학생 화면과 맞는지 | |

## 2. 수업 중 관찰 (맵별, 한 라운드 5~8분)

**공통**: 완주까지 걸린 시간, 막혀서 멈춘 학생 수, 같은 곳에서 떨어진 횟수, 도움 점프가 켜진 횟수와 그 뒤 반응, 도전 별을 얻은 학생의 이후 행동.

| 맵 | 볼 것 | 기록 |
|---|---|---|
| 태양계 | 문 앞 멈춤 시간, 오답 후 첫 힌트와 두 번째 힌트를 읽는지, 정답을 찍는지 이유를 말하는지, 중력 차이를 "조작 난이도"로 받아들이는지 "중력 때문"이라고 말하는지 | |
| 산과 염기 | 색을 보고 판단하는지 다른 학생 타일이 녹는 것을 보고 판단하는지, 같은 틀린 색을 반복하는지 | |
| 전기 회로 | 직렬 문에서 먼저 온 학생의 대기 시간과 말("한 명 더"), 마지막 무리에서 도움이 켜진 횟수, 30초 전에 포기하는 학생, 현황판 "이어진 스위치 N / M"을 읽는지 | |
| 인체 대탐험 | 판막을 혼자 뛰어서 여는 학생과 함께 서는 학생의 수, 안내문("게임 장치")을 읽는지 | |
| 점프 연구소 | 시소에서 양쪽으로 나눠 서는지, 일부러 친구를 떨어뜨리는 행동 | |
| 그 밖의 맵 | 완주 시간 분포, 막힌 구간, 조작 병목 | |

**학급 내 실력 차이**: 숙련자가 쉽다고 하는 구간, 초보자가 막히는 구간(점프 + 다이브 연속 조작), 도움 점프와 도전 별이 충분한지.

## 3. 수업 후 질문 (한 판 뒤 3분, 맵당 2~3개)

이해 증거는 **이유를 말하는 것**과 **새로운 상황에 적용하는 것**이다. 정답 문 통과나 첫 시도 정답률만으로 이해를 판정하지 않는다.

| 맵 | 이유 설명 | 새로운 상황 적용 | 오개념 점검 |
|---|---|---|---|
| 태양계 | 달에서 높이 뛴 건 왜일까요? | 목성에서는 점프가 어떨까요? 이유는? | 우주 정거장에서 떠다니는 건 중력이 없어서일까요? |
| 산과 염기 | 식초 웅덩이에서 붉은 발판만 버틴 이유는? | 비눗물에 붉은 리트머스 종이를 넣으면? | 염기성 용액을 계속 넣으면 산성은 어떻게 될까요? |
| 전기 회로 | 왜 이 문은 모두, 저 문은 하나만 눌러도 열렸나요? | 스위치가 4개인 직렬 문이라면? | 병렬 문의 전구는 하나를 빼도 켜져 있을까요? |
| 인체 대탐험 | 산소는 어디에서 어디로 갔나요? | 이산화탄소는 어느 쪽으로 가나요? | 판막은 실제로 친구가 눌러서 열리나요? |
| 물의 순환 | 구름은 어떻게 생기나요? | 지표수와 지하수는 어디서 다시 만나나요? | 수증기는 눈에 보이나요? |

## 4. 결과 정리

- 재미: 다시 하고 싶다고 한 학생 수, 쉬는 시간에 이어서 한 학생, 가장 좋아한 맵(중력 맵이 가장 인기라는 교사 관찰과 일치하는지).
- 이해: 위 질문에서 이유를 말한 학생 수, 같은 질문에 일주일 뒤에도 답한 학생 수.
- 막힘: 시간 부족과 개념 오해를 같은 실패로 처리하지 않고 따로 적는다.
- 협동: 자발적 도움이 있었는지, 기다린 학생이 지루해했는지, 마지막 학생이 혼자 막힌 일이 있었는지.
- 결과를 바탕으로 고칠 것: 직렬 문 도움 대기 시간(30초), 판막을 필수 협동으로 바꿀지, 태양계 문 순서, 안내판 가독성.

## 5. 바람마을

기본 관찰 질문(길 선택 이유, 해풍·육풍 연결, 풍향계 오해, 역풍 낙하·도움 점프)은 [11. 바람마을 제작](11-바람마을-제작.md)의 "교실에서 볼 것"을 쓴다. 여기서는 그 문서에 없는 항목만 더한다.

- 낮밤을 기다리느라 멈추는 학생이 있는가. Claude의 봇 측정(2026-10-01)에서 해안 한 번 횡단은 순풍 2.0초·역풍 3.5초, 두 번 횡단하는 전체 경로는 낮·밤 모두 12.14초였다. 해당 측정에서는 왕복 효과가 상쇄됐다. 학생이 한 번 횡단의 차이를 느끼는지와 전체 시간을 줄이려고 기다리는지를 나눠 본다. 모든 학생의 시간이 같다고 단정하지 않는다.
- 갈림길에서 H/L로 길을 고르는 학생과 아무 길이나 가는 학생의 비율 (순풍 길이 약 2초 빠를 뿐이라 선택이 별 의미 없게 느껴질 수 있다).
- 21명 방에서 낮밤 반전이 모든 화면에 같은 순간에 보이는가 (`sharedTime()`으로 맞춰지지만 실제 연결에서는 미확인).

## 6. 다른 반 첫 체험 (색과 빛의 미술 공방 기준)

근거: [13. 미술 공방 교실 관찰](13-미술공방-교실-관찰.md). 20명 수업에서 교사가 보고한 것은 "서로 질문하고 답함", "생각 → 선택 → 결과 확인 → 다음 사고·행동", "먼저 통과한 학생이 도움"이다. 도움의 내용과 새로운 상황에서의 적용은 아직 확인하지 않았다. 필수 협동 장치는 더하지 않고 이 장면이 다시 나오는지부터 본다.

**관찰할 장면 (교사가 짧게 기록)**

| 장면 | 기록 |
|---|---|
| 선택 이유: 발판을 고르기 전이나 후에 이유를 말하는가("노랑과 자홍을 섞으면…") | 말한 학생 수, 이유의 내용 |
| 친구에게 한 질문: 무엇을 물었는가(답을 달라 / 이유를 묻는다 / 결과가 왜 이런지 묻는다) | 질문 유형별 횟수 |
| 먼저 통과한 학생의 도움 유형 | ① 정답만 알려 줌 ② 이유를 설명함 ③ 직접 해 보여 줌 ④ 되물어 생각하게 함 |
| 친구의 설명을 듣고 선택을 바꾼 장면 | 바꾸기 전 선택, 들은 말, 바꾼 뒤 결과 |
| 기다리는 행동 | 먼저 통과한 학생이 한 일(구경, 이동, 돕기, 다른 활동), 기다린 시간 |
| 반복 시도 | 같은 작품에서 시도 횟수, 결과를 보고 조합을 바꾸는 속도 |

**수업 후 질문 (3분)**
- "물감과 빛을 섞을 때 결과가 어떻게 달랐나요?"
- "친구의 어떤 말이 다음 선택에 도움이 됐나요?"
- "도와 준 학생: 친구에게 어떻게 설명했나요? 정답을 말해 줬나요, 이유를 말해 줬나요?"
- 다른 표현의 상황에 적용: "노란빛과 파란빛을 같은 곳에 비추면 무슨 색일까요? 노란빛을 어떤 빛으로 만들었는지 떠올려 설명해 보세요." — 게임의 빨강·초록·파랑 발판을 두 빛의 겹침으로 바꿔 묻는다. 수업에서 이미 이 질문을 설명했다면 새 상황 문항으로 쓰지 않는다. 청록+노랑 물감은 첫 초록 작품에서 이미 사용하므로 새 조합 적용 문항이 아니다.

**기록 방법 (이해 증거와 재미 구분)**
- 도움의 유형과 이유 설명 비율이 핵심이다. "정답만 알려 줌"이 많으면 다른 반 학생이 이미 들은 답을 들고 와서 선택·이유 장면이 줄어들 수 있다(미술 공방의 목표 색은 매 판 같다, 코드 확인).
- 다른 반 학생이 같은 학교 친구에게서 답을 미리 들었는지 수업 전에 묻는다. 들었다면 첫 체험의 기준이 달라진다.
- FPS·완주율·연결 지연은 이번 보고에도 없다. 기술 검증이 필요하면 5절·1절과 별도로 측정한다.
