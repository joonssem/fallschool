# 28. 거대 실험실: 물에 띄워 보기 (선택 도전)

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: [14](14-기존맵-수정후보.md) 8번(부력 구간 조작 없음), [22](22-교육내용-점검.md) G2, [23](23-거대실험실-공기실험대.md), [19](19-게임성-반영-기준.md)
- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.**

## 바뀐 것

- 부력 구간(비커) 동쪽에 **물통과 물체 발판**을 추가했다.
  - 발판 5개(나무 블록·코르크 마개·스티로폼·쇠 구슬·돌)와 "물통 비우기" 발판. 발판을 밟으면 그 물체를 물통에 넣는다.
  - 뜨는 물체(나무·코르크·스티로폼)는 물 위에 떠서 **징검다리 칸**이 된다(최대 3칸). 가라앉는 물체(쇠 구슬·돌)는 물속으로 내려가 사라지고 징검다리가 되지 않는다. 메시지로 "물에 떠요/가라앉아요, 물체마다 달라요"를 알려 준다.
  - 뜨는 물체 3개로 3칸을 채우면 물통 끝의 도전 별까지 건널 수 있다. 3칸이 차면 물통을 비워 다시 할 수 있다.
  - 물에 빠지면(틈) 이전 체크포인트에서 다시 시작한다. 안내판에 선택 활동임을 적었다.
- 기본 길(비커 위 발판)은 바뀌지 않았다. 상태는 학생별이다.
- 비커 구역 옆 장식 유리병(`glassware`) 위치를 물통과 겹치지 않게 옮겼다.
- 시험(`tests/giantlab.mjs`, 시드 3 × 출발 시각 2): 처음엔 칸 없음, 쇠 구슬은 칸이 되지 않음, 뜨는 세 물체로 세 칸, 징검다리로 별까지 건넘, 진행 초기화 시 물통이 비워짐, 징검다리 없이는 못 건넘. 전체 `npm test`는 위 결과 외 실패 없음(출력 확인).
- 공통 파일 변경: 없음.

## 과학 범위

- 표현하는 것: 물체마다 물에 뜨는지 가라앉는지가 다르다는 것. 뜨는 물체와 가라앉는 물체를 직접 넣어 비교한다.
- 쓰지 않은 것: 밀도·부력의 크기 식, "가벼워서 뜬다/무거워서 가라앉는다" 같은 단정. 크기가 같아도 물체마다 다르다는 점은 설명하지 않았다(오해 방지). 물체 목록은 일상적인 예이며 모든 나무·돌이 같다는 뜻이 아니다.
- 기존 "부력" 문(`물이 물체를 위로 밀어 올리는 힘`)은 그대로다. 물에 띄워 보기는 그 문의 개념을 직접 만져 보는 선택 활동이다.

## 한계

- 뜨는 물체가 3개로 정해져 있어 "가라앉는 물체를 피하기"만 알면 된다. 물체 선택 외에 판단이 더 필요한지는 관찰 후 판단한다.
- 징검다리 사이 점프(약 2.5~4m)가 터치 조작에서 어려울 수 있다. 어렵다는 관찰이 나오면 칸 간격을 줄인다(`SLOTS`).
- 물체가 같은 크기일 때 뜨고 가라앉는 이유(물질의 차이)는 설명하지 않는다. 필요하면 후속으로 같은 크기 비교를 추가한다.

## 교실에서 볼 장면

1. 어떤 물체부터 넣는지, 가라앉는 것을 보고 다른 물체로 바꾸는지.
2. "나무·코르크·스티로폼은 뜬다"를 자기 말로 하는지, 쇠·돌과 비교하는지.
3. 징검다리를 건너다 물에 빠지는 빈도와 포기하는 학생이 있는지.
4. 물체 발판과 안내판이 가까워 오입력이 생기는지(발판 간격 2.3m).
