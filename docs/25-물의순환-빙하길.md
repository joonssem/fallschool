# 25. 물의 순환: 빙하 길과 얼음 바닥 (선택 길)

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: 교사 의견("물의 순환 구름 공장은 너무 단순함. 얼음도 등장해서 바닥면이 미끄러운 상황 추가"), [14](14-기존맵-수정후보.md), [19](19-게임성-반영-기준.md), 앞 작업 [24](24-물의순환-증발상승기.md)
- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.** 교사 의견은 교사 보고이며 효과 검증이 아니다.

## 바뀐 것

- **빙하 길**을 땅에 닿은 물의 갈림길(지표수·지하수)의 **서쪽에 세 번째 길**로 추가했다. 같은 강 하구로 이어진다.
  - 얼음 바닥(7m 폭 × 25m): 가속·감속이 느려 달리다 손을 떼면 7m 남짓 미끄러진다(보통 바닥은 0.5m, 시험으로 측정). 방향을 바꾸는 힘도 작다.
  - 지그재그로 선 얼음 기둥 4개를 돌아 나간다(점프로 넘어도 된다). 양옆은 눈 둔덕이 막아 미끄러져도 떨어지지 않는다(일부러 뛰어넘으면 떨어질 수 있다).
  - 입구·출구는 눈 쌓인 보통 바닥이다. 안내판: "물이 얼음(고체)으로 쌓여 있어요 / 미끄러워요 · 녹은 물은 강으로 가요".
  - 구간명을 `지표수·지하수·빙하`로, 강 하구 안내를 "지표수·지하수·빙하 녹은 물이 바다로 모여요"로 바꿨다.
  - 지표수 안내판이 빙하 길 위에 떠 보이지 않도록 지표수 길 위로 옮겼다.
- 기본 완주는 바뀌지 않았다. 기존 경로는 그대로이고 빙하 길은 선택이다.
- **공통 파일 변경 (호환 영향 기록)**:
  - `src/physics.js`: `BoxCollider` 옵션에 `icy` 추가 (기본 `false`).
  - `src/player.js`: `TUNING.iceAccel` 9, `iceDecel` 3.2 추가. 바닥이 `icy`일 때만 지상 가속·감속을 이 값으로 바꾼다.
  - 기존 바닥은 `icy`가 없어 동작이 같다. 전체 `npm test` 17개 묶음 통과로 확인했다(규칙·이동 검증). 다른 맵도 `platform(..., { icy: true })`로 얼음 바닥을 쓸 수 있다.
- 시험: `tests/water-lift.mjs`에 얼음 시험 추가(미끄러진 거리 비교, 기둥 사이 완주, 곧장 달려도 완주, 옆으로 달려도 안 떨어짐).

## 과학 범위

- 표현하는 것: 물의 세 가지 상태 중 **고체(얼음)** 가 순환에 나온다. 빙하가 녹아 강으로 흐른다.
- 쓰지 않은 것: 빙하의 이동·해수면 같은 설명. 얼음이 미끄러운 것은 게임의 체험 요소이며 학습 목표는 아니다.
- 이미 있던 "구름은 물방울이나 얼음 알갱이" 안내와 이어진다. 구름·강수 구간은 바뀌지 않았다.

## 한계와 후속 후보

- 교사의 "너무 단순" 의견에 대해 이번에는 **선택 길 하나와 이동 규칙 하나**만 더했다. 맵 전체의 단순함이 해소되었다고 말할 수 없다. 응결 문 하나만 있는 개념 판단, 구름·강수 구간의 일직선 이동은 그대로다.
- 후속 후보(미설계): ① 강수 구간에 눈·우박(얼음 알갱이)이 내려 일부 발판이 얼어 미끄러운 선택 경로, ② 햇빛 아래에서 얼음이 녹아 물로 바뀌는 발판, ③ 바다와 하구를 오가는 순환 임무. 얼음 바닥이 필수 경로가 되지 않게 해야 한다(조작 부담 완화).
- 얼음 바닥이 터치 조작(iPad)에서 너무 미끄러운지는 교실에서 확인해야 한다. 값(`iceAccel`, `iceDecel`)은 한 곳에서 조정한다.

## 교실에서 볼 장면

1. 학생이 빙하 길을 고르는가, 고른 학생이 한 번에 지나가는가, 반복해서 미끄러지며 노는가.
2. 얼음에서 멈추려고 미리 손을 떼는 모습이 나오는가, 기둥에 계속 부딪히는가.
3. 빙하 길 학생이 "얼음이 녹으면 강으로 가요" 안내를 읽는가.
4. 얼음 길 때문에 갈림길에서 오래 머무르거나 포기하는 학생이 있는가.

## 추가: 눈 구름 길 (같은 날 후속, 선택 길)

- 교사 의견("너무 단순")에 이어 **강수 구간에도 선택 길을 추가**했다. 기본 구름 길(비)은 그대로다.
  - 기본 구름 길 서쪽에 **눈 구름 길**: 눈 쌓인 구름 발판 세 칸(얼음 바닥, 9×6m). 같은 착지점('비가 내리는 곳')으로 이어진다. 눈송이가 내리는 장식이 있다.
  - 서쪽 가장자리와 가운데 칸 동쪽에 눈 둔덕이 있어 옆으로는 잘 미끄러져 떨어지지 않는다. 첫 칸 입구와 끝 칸 출구는 열려 있다.
  - 가운데 칸 서쪽 둔덕 너머에 **도전 별**이 있다. 미끄러운 바닥에서 방향을 잡아 뛰어야 한다.
  - 안내판: "눈 구름 길 (선택) / 아주 차가운 구름에서는 눈이 내려요 / 눈 쌓인 바닥은 미끄러워요". 강수 안내판을 "구름 속 물방울·얼음 알갱이가 비나 눈이 되어 내려요"로 고쳐 비와 눈이 모두 강수임을 보인다.
- 과학 범위: 구름 속 기온이 아주 낮으면 눈이 내린다는 것까지. 눈이 쌓여 빙하가 된다는 설명은 쓰지 않았다(앞의 빙하 길과 직접 연결하지 않음).
- 시험(`tests/water-lift.mjs`): 눈 구름 길 완주(시드 3 × 출발 시각 2), 곧장 달려도 착지점으로 이어짐, 둔덕 너머 별에 닿음. 전체 `npm test` 통과. 기본 구름 길 시험(`body-water.mjs water`)도 그대로 통과.
- 시험 중 발견: 마지막 눈 칸을 착지점에서 3m 띄워 두면 얼음에서 속도를 내기 어려워 건너뛰기 어려웠다. 그래서 마지막 칸을 착지점에 거의 붙였다(틈 0.5m).
- 점검표 요약: 핵심 재미 = 미끄러운 눈 구름을 타는 이동. 선택 = 비 구름 길 대 눈 구름 길(같은 곳 도착), 별은 눈 길에서만. 재시도 = 둔덕이 있고 떨어져도 체크포인트로 돌아온다(응결 구름이나 직전 체크포인트, 최대 약 20m 되돌아감 `[추론]`). 기본 완주 = 기존 길 그대로. 근거 = 코드·시험(규칙·이동), 화면·교실 반응 미확인.
- 교실에서 더 볼 것: 눈 구름 길을 고르는 비율, 입구·출구에서 떨어지는 빈도, 별 시도, iPad에서 미끄러움이 과한지. 미끄러운 길이 두 곳(눈 구름·빙하 길)이므로 얼음 바닥이 지루하거나 부담스러운지 비교한다.
