# 37. 메아리 탐정단 제작·후속 반영 기록

2026-10-02. Codex 신규 맵 제작. 기존 맵 수정 없이 새 `echodetective` 맵을 등록했다. 제작 전 [18. 전체 맵 게임성 분석](18-전체맵-게임성-분석.md)과 [19. 게임성 반영 기준](19-게임성-반영-기준.md)을 확인했다.

## Claude 검토 후 구현 현황

아래 첫 제작 메모의 일부 설명은 초안 기준이다. 현재 코드는 이 절을 기준으로 확인한다. 검토 내용과 수정 근거는 [34. 새 맵 3개 검토](34-새맵3개-검토.md), 요청은 [35. Codex 전달](35-Codex-전달-새맵검토.md) 참고.

- 방향 원판에서 시작한 고리가 대응하는 벽까지 이동한 뒤 출발점으로 돌아온다. 반사면 거리는 각각 6·12, 12·6, 8·10 게임 단위라 왕복 애니메이션은 0.6·1.2초, 1.2·0.6초, 0.8·1.0초다. 화면 시간은 애니메이션 길이와 맞지만 실제 음속을 뜻하지 않는다.
- 시작 안내에는 실제 소리는 사방으로 퍼지며 이 맵은 한 방향씩 보내는 단순 모형이라고 적었다. 스캔 직후에는 거리 수치를 보여 주지 않고, 신호가 돌아온 뒤 왕복 시간만 알린다. 가까운 면 쪽 길을 탐험하면 조각과 거리 표식을 발견한다. 먼 면 쪽도 안전하게 합류하고 기본 완주는 가능하다.
- 반사면 벽은 통로 바깥에 있고 충돌체가 켜져 있다. 가까운 면 조각 3개는 마지막 장면에 별도로 나타난다. 재체험은 첫 체험 목표의 초기화이며 새로운 규칙이나 지형은 아직 없다.
- 전용 자동 검증은 시간 애니메이션, 실제 걸음으로 가까운 쪽 보상 수집·완주, 먼 쪽의 안전한 탐험, 스캔을 건너뛴 완주, 초기화를 확인한다. 화면·터치·교실 검증은 아직 하지 않았다.

## 플레이 설계

- **핵심 행동**: 학생이 좌우 스캔 원판에서 보내고 돌아오는 고리를 본 뒤 시간을 비교하고, 갈림길에서 원하는 통로를 직접 걷는다.
- **선택과 결과**: 가까운 반사면 쪽 통로에만 선택 조각과 거리를 표시한다. 먼 쪽도 안전하게 연결되며 선택 조각은 완주 조건이 아니다.
- **다음 행동**: 가까운 쪽을 골라 조각을 모으거나 먼 쪽을 자유 탐험한 뒤 다음 동굴로 이동한다. 세 구역에서 거리 관계가 달라진다.
- **재체험 용도**: 첫 체험용 탐험 맵이다. 재시작하면 스캔과 표식 발견이 초기화되어 다른 순서로 살펴볼 수 있지만, 아직 시드별 지형 변화나 새 해결 규칙을 제공하지 않는다.
- **학습 범위**: 반사된 소리가 돌아올 수 있고 반사면이 멀수록 왕복 시간이 길어진다는 관계를 다룬다. 방향은 스캔 원판 선택으로 정하며 시간만으로 방향을 알아낸다고 표현하지 않는다. 실제 소리는 사방으로 퍼지지만 여기서는 한 방향씩 보내는 단순 모형임을 시작 안내에 밝힌다.

## 구현 범위와 호환 영향

- `prototype/src/levels/echodetective.js`를 추가하고 맵 선택 목록에 등록했다. 기존 공용 키트·플레이어 조작은 수정하지 않았다.
- `package.json`의 자동 검증에 새 맵 테스트를 등록했다. 맵 개수 검사는 Claude가 로봇 걸음 시험을 합친 상태에서 15개로 확인한다.
- 소리의 전파·반사·속도는 실제 음향을 재현하지 않는다. 일차원 이동 고리와 임의 게임 거리 단위로, 왕복 시간은 `2 × 거리 ÷ 애니메이션 속도`로 정한다. 사용자에게 실제 음속 수치로 제시하지 않는다.

## 검증과 교실 관찰

- 자동 테스트는 시간에 맞춘 왕복 애니메이션, 통로별 보상, 가까운 쪽 선택·스캔 건너뛰기와 완주를 확인한다. 통과는 코드 규칙과 이동 검증이며 재미·학습 효과의 증거가 아니다.
- **교실 검증 전**: 학생이 가까운 쪽의 짧은 왕복 신호를 보고 그 통로를 선택하는지, 스캔을 건너뛸 때도 길을 찾는지, 먼 통로 조각이 없을 때 되돌아가 다른 길을 시도하는지, 안내문과 고리가 PC·iPad 화면에 읽히는지 관찰한다.
- **교사 보고·코드 기반 추정·실제 학생 관찰**은 서로 다른 근거로 기록한다. 현 시점에 이 맵의 교실 시험이나 교사 보고는 없다.
