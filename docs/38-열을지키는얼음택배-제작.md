## Claude 검토 후 구현 현황

현재 동작은 이 절을 기준으로 한다. 첫 구현 당시의 메모는 아래에 남겼다. 문제 검토는 [34. 새 맵 3개 검토](34-새맵3개-검토.md), 요청은 [35. Codex 전달](35-Codex-전달-새맵검토.md)을 참고한다.

- 포장은 실제 재료 유형을 주장하지 않는 **게임 포장 A·B·C**다. 고정 시험은 같은 양·주변 조건·2.5 게임 시간에 포장 모형 값만 비교한다.
- 배송 결과는 포장 선택과 햇빛·그늘 경로의 길이·햇빛 노출을 함께 사용한다. A에서는 그늘 경로, C에서는 짧은 햇빛 경로가 더 많은 얼음을 남기며 여섯 조합이 모두 안전 배송 범위다. 예시 게임 모형 잔량(햇빛/그늘): A 14.2%/23.2%, B 39.1%/43.2%, C 60.4%/58.2%. 이는 실제 물질 성능이나 교실 측정이 아니다.
- 포장 선택을 건너뛰어도 외곽 우회로로 비교 공간을 지나갈 수 있고, 도착 시 기본 포장 A를 사용한다. 배송 길에 들어설 때는 경로만 선택하고, 공연장 도착 지점에 이르러서 잔량·소품 수·무대색·문 상태가 바뀐다. 발판 없는 옆 우회로를 막는 문은 틈 전체를 덮는다.
- 전용 검증은 3×2 결과표, 경로 이점이 포장에 따라 달라지는 것, 포장 선택 건너뛰기, 도착 전 결과 미표시, 도착 후 변경, 실제 걸음 완주를 확인한다. 화면·터치·교실 근거는 아직 없다.

## 첫 버전 플레이 흐름

1. (첫 버전) 같은 양의 얼음, 주변 조건, 2.5 게임 시간으로 포장 값을 비교했다. 실제 재료 성능이 아닌 점은 현재도 같다.
2. (현재) 이름을 포장 A·B·C로 바꿔 재료 속성을 단정하지 않는다. 원하는 경우에만 하나를 고른다.
3. (현재) 길이와 햇빛 노출이 반대 방향으로 작용하는 두 배송 경로를 직접 걷는다. 포장 값에 따라 잔량 결과가 달라진다.
4. (현재) 도착 지점에서 남은 양, 얼음 조각 수, 무대색을 확인하고 길이 열린다. 모든 조합은 완주 가능하다.

재시도는 체크포인트를 통해 가까운 경로 선택 지점에서 시작한다. 이전 포장 시험 구역으로 돌아가 포장을 바꾸고 새 경로를 고를 수 있다. 실패로 학생을 탈락시키지 않는다. 개인 상태라 다른 학생의 선택이 내 화물을 바꾸지 않는다.

## 교육 표현의 범위

단열은 열의 이동을 줄이는 것으로 설명한다. “차가움이 밖으로 샌다”거나 포장이 냉기를 만든다고 말하지 않는다. 비교 결과는 실제 재료의 성능 순위가 아니라, 같은 조건에서 차이를 보이기 위해 정한 **게임 속 단순 모형**이다. 자유 배송 장면은 게임 시간·경로·노출을 함께 반영하므로 포장 하나만의 과학 실험 결과로 해석하지 않는다.

## 검증 및 교실 관찰

전용 시험은 고정 시험시간, 포장×경로 잔량 표, 경로 이점이 포장별로 뒤집히는 점, 여섯 조합의 배송 가능성, 포장 선택 건너뛰기, 목적지 도착 전후 변화, 실제 이동 완주와 초기화를 확인한다. 이는 규칙·이동 검증이지 재미·학습 효과의 증거가 아니다. 브라우저 화면, iPad 터치·가독성·FPS, 실제 교실은 확인이 필요하다.

교실에서는 A/B/C 중 학생이 선택·생략한 이유, 짧은 햇빛 길과 긴 그늘 길을 고른 근거, 목적지 잔량을 앞선 선택과 연결하는지, 도착 전에 결과를 기대하는지 관찰한다. 외곽길로 포장 비교를 건너뛰는지와 터치 발판 오입력도 기록한다. 수업 뒤 “이 포장에서는 왜 다른 길을 골랐나요?”를 묻는다. 첫 체험과 재체험을 구분한다.

### 모형 (게임 값, 실제 재료 성능이 아님)

- `iceDelivery2` = 포장 손실 × 1.5 + 길 거리 × 0.005 + 노출 × 1.6(더운 날) × 포장 햇빛 차단. 새 얼음을 배달하므로 1차 결과(남은 양)는 2차 얼음에 이어지지 않는다. 1차 결과는 도착 안내판의 "1차 xx% · 2차 yy%"와 포장 선택의 단서로 쓰인다.
- 남은 얼음(%, 고갯길/숲길/터널): 포장 A 13/32/42, 포장 B 39/49/54, 포장 C 65/65/63. 모든 조합이 배달 가능하다(실패 없음). 포장마다 가장 좋은 길이 모두 같지는 않다(A·B 터널, C 숲길 근소).
- 고갯길은 열적으로는 불리하지만 **별**(바위턱 위, 포장 A·B만 올라감)이 있다. 포장 C는 바위턱을 못 올라 숲길·터널로 간다(1차와 같은 무게 규칙을 새 상황에 다시 적용).
- 2차 큰 공연(60% 이상 남음)은 포장 C로만 가능하다. 별 개수: 3 → 5.
- 2차 화물은 갈림길부터 든다(무게 적용). 재포장소로 되돌아오면 내려놓고 길을 다시 고를 수 있다.

### 시험 (`tests/icetaxi.mjs` 47건, 걷기)

- 세 길 모두 출발부터 두 번째 공연장 결승까지 걸어서 완주(재포장 건너뜀). 재포장 C → A로 바꾸면 고갯길 바위턱을 올라 별을 얻고, 포장 C(2차)는 바위턱에서 막힘. 포장 C + 숲길은 2차 큰 공연 별을 얻음, 포장 B + 터널은 안 나타남.
- 갈림길 앞으로 되돌아오면 길 선택이 풀림, 초기화로 2차 상태·별·문이 처음으로.
- 길이 200m 이상, 체크포인트 간격 45m 이하. 전체 `npm test` 통과. 자동 시험은 이동·규칙 확인일 뿐 재미나 학습 효과의 증거가 아니다.

### 미확인

- 길이가 늘어서 학생이 지루해하거나 중간에 그만두는지, 재포장을 실제로 쓰는지, 1차와 2차의 숫자 비교를 이해하는지(교실).
- 터널 벽 사이(틈 1.6m) 지그재그 걷기의 iPad 터치 부담, 3줄 안내판의 글자 크기와 가독성(화면).
- 길 거리·노출·더운 날 계수(1.6)는 게임 모형이다. 교사의 과학 표현 확인이 필요하다("햇빛이 닿지 않아요" 정도만 표현하고 온도 수치는 쓰지 않았다).
