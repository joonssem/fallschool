## 2. 게임 구조

### 2.1 쇼(한 판)

- 여러 명이 무작위로 뽑힌 미니게임 라운드를 거치며 탈락하고, 마지막 한 명(스쿼드면 한 팀)이 우승한다.
- 인원 변화

| 시기 | 기본 모드 인원 | 라운드 수 |
|---|---|---|
| 2020 출시 | 60명 (모자라면 조금 적게 시작) | 보통 5 (3~6) |
| 2023년 2월 | 36~40명 (매칭을 빠르게) | — |
| 2023년 9월 (실험) | 28~32명 "Quick Solos" | 약 4 |
| 2024년 5월~ "Knockout" | **32명** | **3** |

- Knockout(2024, "Fall Forever" 업데이트): 기존 Solos를 대신한 기본 모드. **라운드 풀 40개**를 유지하며 주기적으로 바꾸고, 공식 라운드와 **플레이어가 크리에이티브로 만든 라운드**를 섞는다. 쇼를 짧게 줄여 균형을 맞추려 했다고 밝혔다. Duos·Squads도 같은 라운드 풀.

### 2.2 게임 시간 (대략)

| 단위 | 시간 |
|---|---|
| 라운드 하나 | 보통 2~3분, 길어야 약 5분 |
| 결승 | 제한 시간 대개 5분 |
| 쇼 한 판 (탈락 시점에 따라) | 평균 5~10분, 넓게 2~15분 |
| 60명·5라운드 끝까지 (초기) | 약 15~20분 |

### 2.3 라운드 종류 (7가지)

| 종류 | 내용 |
|---|---|
| 달리기 (Course) | 결승선까지 달리기, 먼저 도착한 인원이 통과 |
| 버티기 (Survival) | 떨어지지 않고 버티기 |
| 점수 (Points) | 스포트라이트 아래 머물기, 물건 모으기 등 점수 경쟁 |
| 팀 (Team) | 팀으로 협력·경쟁 |
| 논리 (Logic) | 3~5개 문제 상황에 알맞게 행동해야 생존 (예: 기억한 그림 위에 서기) |
| 숨바꼭질 (Invisibeans) | 숨은 역할 찾기 |
| 결승 (Final) | 마지막 우승자 결정 |

- 첫 라운드는 대개 곧은 달리기로 약 1/3을 한꺼번에 떨어뜨린다는 설명이 있다 (가이드 사이트, 신뢰도 낮음).

### 2.4 조작

| 동작 | 내용 |
|---|---|
| 이동·점프 | 대부분의 라운드는 달리기와 점프만으로 된다 |
| 다이브 | 멀리뛰기. 땅이나 **공중에서** 쓸 수 있어 보통 점프로 못 건너는 틈을 건넌다 |
| 잡기 | 꼬리 잡기, 왕관 잡기, 알 옮기기 라운드에 필수. 다른 플레이어도 잡을 수 있다 |

### 2.5 설계 원칙 (개발진 발언)

- **"세 단어로 설명할 수 있는 게임만"**: 놀이터 놀이·게임쇼의 느낌을 지키려는 내부 규칙.
- 캐릭터 움직임: **웃기게 실패할 만큼 흔들리지만, 실력이 드러날 만큼 정확하게.** 가볍게 즐기는 사람과 실력을 쌓는 사람을 함께 끌어들이는 균형.
- 배틀로얄 결승의 긴장감을 더 친근하고 격려하는 분위기로 옮기려 했다.
- 단순한 그림체: 게임쇼 분위기 + 화면에 혼란이 많아도 읽기 쉽게.

### 2.6 크리에이티브 (플레이어 제작)

- 2023년 5월 10일 출시. 달리기·버티기·점수 라운드를 만들 수 있다.
- 부품 예산 2500점으로 한 라운드에 넣을 물건 수를 제한한다.
- 완성·테스트·게시하면 **12자리 공유 코드**가 생기고, 친구와 비공개 로비에서 하거나 탐색 모드에 노출된다.

## 3. 우리 게임과 비교

| 항목 | Fall Guys | 우리 게임 (9/29 기준) |
|---|---|---|
| 인원 | 32명 (Knockout) | 학급 21명 |
| 라운드 길이 | 달리기 2~3분 | 맵 하나 완주 1~2분 (21명 시험) |
| 한 판 | 3라운드, 5~10분 | 교사가 맵을 하나씩 골라 진행 (묶음 기능 없음) |
| 탈락 | 라운드마다 탈락 | 탈락 없음, 체크포인트 복귀, 학급 완주 수 |
| 조작 | 이동·점프·다이브·잡기 | 이동·점프·다이브 (잡기는 뺌) |
| 라운드 종류 | 7가지 | 달리기 + 예측 문(논리) + 색 발판(논리) + 스위치 문(팀) + 시소 |
| 플레이어 제작 | 크리에이티브, 공유 코드 | 종이 설계 → Claude가 맵으로 (1단계) |
| 난이도 폭 | 흔들리는 움직임 + 실력 표현 | 도전 별(잘하는 학생), 도움 점프(막히는 학생), 외나무 지름길 |

## 4. 시사점

1. **맵 길이는 이미 원작 수준이다.** 완주 1~2분은 원작 달리기 라운드(2~3분)와 비슷하다. 맵을 늘리기보다 **여러 맵을 이어 한 판(쇼)** 으로 만드는 것이 원작에 가깝다.
2. **학급 규모 = 원작 Knockout 규모.** 21명·3라운드·10~15분이 원작 구조와 거의 같다. 3라운드 사이에 1~3분 되돌아보기를 넣으면 [01](01-게임성-탐색.md) 4장의 40분 쇼 흐름이 된다.
3. **"세 단어 규칙"을 우리 장애물과 학생 설계 기준에 넣는다.** 예: "맞는 문 고르기", "같은 색 밟기", "스위치 함께 누르기", "나눠 서서 균형". 세 단어로 설명이 안 되면 장애물이 복잡하다는 신호.
4. **원작의 "논리" 라운드가 우리 예측 문·색 발판과 같은 계열이다.** 원작은 3~5개 문제를 한 라운드에 넣는다. 우리 맵(문 2~4개)과 비슷한 밀도.
5. **원작도 플레이어 제작 라운드를 정식 풀에 넣는다.** 학생 맵 설계 활동이 원작 운영 방식과 같은 방향. 원작처럼 **부품 예산**(예: 장애물 카드 4장까지)을 두면 설계가 간결해진다.
6. **잡기는 원작의 핵심 조작 중 하나다.** 원작을 아는 학생이 잡기를 시도한 까닭. 방해에 쓰이지 않는 형태(물건 옮기기·협동 운반)로만 다시 들이는 것을 나중에 검토할 수 있다.
7. **"웃기게 실패, 정확한 실력"의 균형**은 도움 점프(막히는 학생)와 도전 별·외나무 지름길(잘하는 학생)로 우리도 맞추고 있다. 교실 시험에서 확인할 것.
8. **탈락 대신 복귀**는 원작과 일부러 다른 점이다. 원작의 긴장감은 탈락에서 오므로, 우리는 학급 완주 수·첫 시도 정답·도전 별 같은 **함께 채우는 목표**로 긴장감을 대신한다.
