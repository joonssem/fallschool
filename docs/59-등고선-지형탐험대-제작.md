# 59. 등고선 지형 탐험대 — 제작 기록

## 현재 동작 요약 (2026-10-06 기준)

- 답사 본부에서 산지·하천·해안으로 바로 출발하고, 평야는 산지 답사 또는 하천 건넘 결과 중 하나를 얻은 뒤 들어가는 고정 지도 첫 체험 맵이다.
- 산지에서는 등고선 간격과 경사를 보고 완만한 길·능선 길을 고른다. 하천에서는 북쪽·하류 쪽 건넘길을 고르면 그 방향의 평야 연결이 열린다.
- 평야에서는 실제 지명이 아닌 두 후보 장터 터를 비교한다. 선택한 터에 따라 하천 하류 연결 또는 완만한 해안 연결이 나타난다.
- 필수 해안은 서·남쪽의 굴곡진 해안이고, 동쪽의 단순한 해안은 선택 답사다. 선택 별 1개는 동쪽 해안 방향에서 걸어서 얻는다.
- 수첩·표식·열린 길은 레벨 인스턴스의 상태로 관리한다. 낙하해도 완료 표식이 유지되고 가까운 정적 체크포인트에서 이어간다.
- 대표 세 동선의 설계 waypoint 추정 길이는 약 197~202m다. 실제 지형을 축척대로 재현하지 않은 지형도 모형이며, 시드로 위치가 바뀌지 않는다.
- 봇 걷기 시험은 통과했다. 화면 가독성·iPad 터치·교사 시연·교실 학습 효과는 아직 확인하지 않았다.

## 맵 구성과 선택 결과

| 구역 | 학생의 핵심 행동 | 눈에 보이는 선택 결과 | 다음 행동 | 기본/선택 |
|---|---|---|---|---|
| 산지 | 등고선 간격과 경사 모형을 보고 완만한 길 또는 능선 길 선택 | 산지 기록과 평야 북쪽 진입 연결이 열림 | 열린 북쪽 길을 따라 평야로 이동 | 필수 답사, 둘 중 경로 선택 |
| 하천 | 북쪽 건넘 또는 하류 쪽 건넘 선택 | 고른 방향의 평야 진입로가 열리고 반대편 표식에서 가까이 재선택 가능 | 열린 강가 길로 평야에 진입 | 필수 답사, 건넘 방향 선택 |
| 평야 | 강가의 넓은 터와 완만한 언덕 터를 비교해 장터 후보 선택 | 선택한 터 표식과 다음 연결로가 나타남 | 하류 길 또는 해안 길로 이동 | 필수 답사, 터 선택 |
| 서·남쪽 해안 | 굴곡진 해안선을 따라 현장 표식까지 걸어 답사 | 필수 해안 기록과 본부 복귀길이 열림 | 선택 복귀길을 이용하거나 기존 길로 이동 | 필수 |
| 동쪽 해안 | 단순한 해안선을 비교 답사 | 선택 해안 표식과 별을 얻음 | 본부·산지로 돌아가거나 계속 탐험 | 선택, 생략 가능 |

계획서와 구현의 차이: 평야 진입을 산지 한 길·하천 한 길로 한정하지 않고 하천의 북쪽과 남쪽 중 관찰한 건넘 방향을 선택하게 했다. 세 번째 방문 순서가 가능하도록 평야에서 하류 연결을 제공한다. 첫 버전에는 실제 촌락·장터 지명이나 실증된 입지 판단을 넣지 않았고, 후보 터의 차이는 가상 이동 경로 선택으로만 표현한다. 활동의 학습 효과나 지역 입지 타당성은 검증하지 않았다.

## 기존 맵과 구별되는 실제 행동

`유적 발굴 현장`은 지표 단서를 보고 발굴 도구·장소를 정하고, 발굴 결과로 다음 통로가 달라지는 구역형 맵이다. 이 맵은 정해진 전방 코스를 통과하는 대신 본부 지형도를 읽고 서로 다른 방향의 현장을 자유 순서로 찾아가며, 답사 기록을 본부 분포 표식으로 누적한다. 산지의 경사 길, 하천의 건넘 위치, 평야의 후보 터, 해안선 비교가 각기 다른 공간 행동을 만든다. 공통적인 발판 조작이나 결과판 뒤 문 열기를 핵심 루프로 쓰지 않는다.

## 자동 시험 결과와 설계 확인

### 봇 걷기·규칙 검증

`prototype/tests/terrainexpedition.mjs`에서 봇이 `run(...)`으로 직접 이동한다.

- [x] 서로 다른 지정 순서 세 가지로 필수 답사 후 결승에 도착.
- [x] 답사 전에 평야 입구가 닫혀 있고 입구를 통과할 수 없음.
- [x] 산지 쪽 결과와 하천 쪽 결과 모두 평야 입구를 엶.
- [x] 선택 동쪽 해안과 별을 건너뛰고 완주.
- [x] 평야 장터·하천 건넘 선택을 가까운 위치에서 수정.
- [x] 낙하 뒤 수첩·표식·열린 하천 연결 유지.
- [x] 동쪽 해안 선택 별에 걸어서 도달.
- [ ] 길이 170~220m는 **달성하지 못함**. 봇이 실제로 걸은 구간의 직선 합(2026-10-06 측정): 산지→하천→평야→해안 246m, 하천→평야→해안→산지 250m, 해안→산지→평야→하천 265m. 본부를 오가는 순서일수록 길어진다. 시험은 170~280m를 안전 범위로 두고, 250m(AGENTS.md 기준) 초과는 다음 보완 후보로 둔다(본부 왕복을 줄이는 지름길 등).
- [x] 전체 `prototype`의 `npm test` 통과. 기존 전체 맵 시험, `maps-meta.mjs`, `map-rules.mjs`, 새 맵 걷기 시험을 모두 실행했다.

이 시험은 등록·규칙·이동 가능성 검증이다. 거리값은 봇이 걸어서 성공한 구간의 waypoint 직선 합이며, 물리 엔진의 누적 이동거리가 아니다(실제 이동은 더 길 수 있다). 처음 문서에 적었던 '170~220m 추정'은 손으로 더한 계획값이었고 위 실측과 달라 고쳤다. 시험 통과를 재미, 개념 학습 또는 수업 효과의 증거로 해석하지 않는다.

### 사람이 점검할 설계 항목

- [ ] 산지·하천에서 올바른 지형 단서를 보면 가장 편한 기본 연결을 찾을 수 있는지 확인.
- [ ] 각 선택의 이득과 대가가 화면에서 보이고 학생에게 선택 이유가 생기는지 확인.
- [ ] 선택 결과가 다음 이동에 실제로 쓰인다는 점을 안내 없이 알아차리는지 확인.
- [ ] 지형 위치·분포를 탐구하게 하고 정답 숫자를 그대로 입력시키지 않는지 교사 검토.
- [ ] 지도 단서와 현장 대응이 가독성 있게 보이는지 화면 크기별 검토.
- [ ] 체크포인트, 재선택 위치, 이동 폭을 iPad 터치로 확인.
- [ ] 교실에서 5~6학년 학생이 자유 순서를 이해하고 각 구역 행동을 구별하는지 관찰.
