# 17. 그림자 변신 극장 제작

2026-10-01. [새 맵 아이디어](16-새로운-맵-아이디어.md)의 첫 우선순위를 구현했다. 미술 공방의 교사 관찰을 참고했으며 이 맵의 재미와 학습 효과는 아직 교실에서 확인하지 않았다.

## 네 무대

1. 거리: 작은 광원과 화면을 고정하고 물체를 앞뒤로 움직여 목표 그림자 크기를 만든다.
2. 방향: 같은 직육면체를 돌려 정면과 옆면의 투영을 비교한다.
3. 위치: 물체를 위·아래·좌·우로 움직여 목표 그림자 자리에 맞춘다.
4. 조합: 세로 막대와 가로 막대를 각각 선택해 움직이고 두 그림자로 공연 모양을 만든다.

발판을 밟을 때 한 단계 바뀐다. 내렸다 다시 밟으면 추가로 바뀐다. 왼쪽에는 빛·물체·화면의 작은 입체 모형, 오른쪽에는 같은 그림자의 확대 화면이 있다. 검은 그림자와 청록색 목표 점선을 즉시 비교한다. 목표와 맞춘 뒤 `공연 완성` 발판을 밟으면 길이 열린다.

오답은 메시지만 표시하고 떨어뜨리지 않는다. 선택은 학생마다 독립적이며 친구가 내 발판을 밟아도 내 상태는 바뀌지 않는다. `처음 모양`은 실험을 되돌리되 완성한 길은 유지한다. 새 경기와 처음부터 시작하기는 선택·문·시도 횟수를 초기화한다. 체크포인트 네 곳, 출발점, 선택 도전 별과 결승이 있다. 필수 동시 협동은 없다.

## 첫 버전 게임성 점검

| 항목 | 첫 버전 확인·남은 과제 |
|---|---|
| 핵심 재미 | 물체 조작에 따라 그림자를 바꾸고 목표 실루엣을 만든다. 교실 재미는 미확인. |
| 의미 있는 선택 | 거리·회전·자리·선택 물체가 투영 결과를 바꾼다. 정해진 횟수 암기 가능성은 관찰 대상. |
| 즉시 결과 | 작은 입체 모형과 확대 화면을 같은 투영으로 갱신한다. |
| 다음 행동·성취 | 완료하면 통과 길이 열린다. 실제 공연 장면으로 이어지는 보상은 후속 과제. |
| 구간 변화 | 거리 → 회전 → 위치 → 두 물체. 마지막에 거리·회전까지 종합하지는 않는다. |
| 재시도 부담 | 오답은 메시지만 표시하고 완료 경로를 유지한다. 발판 왕복·터치 오입력은 실기 관찰 필요. |
| 기본 완주·선택 도전 | 네 무대가 기본 경로이고 도전 별은 선택이다. 동시 협동을 요구하지 않는다. |
| 친구와의 연결 | 개인 상태로 설명·조언을 받을 수 있다. 자발적 도움이 실제 발생하는지는 미확인. |
| 재체험 용도 | 고정 목표의 첫 체험용. 반복 시 새로운 판단을 만드는 변형은 미구현. |
| 근거·관찰 | 규칙·이동 시험과 PC 화면 확인. 학생의 이유 설명·다음 선택 수정·왕복 부담은 교실에서 확인. |

## 과학 표현과 계산

작은 점광원 하나와 불투명한 직육면체를 단순화한 모형이다. 광원과 화면 사이에서 물체 꼭짓점을 투영해 윤곽을 만들고, 두 물체는 그림자의 합집합으로 판정한다. 화면의 그림자와 정답 판정은 같은 투영을 사용한다. GPU의 조명 그림자를 정답 판정에 쓰지 않는다.

광원과 화면이 고정된 조건에서 물체를 광원에 가까이 옮기면 그림자가 커진다. 이 결과를 태양빛처럼 거의 평행한 빛에 그대로 적용하지 않는다. 광원의 크기에 따른 반그림자·여러 광원·투명체·색 그림자는 이번 범위에 없다. 근거 자료는 아이디어 문서의 Science World와 Ontario Science Centre 링크에 정리했다.

첫 버전 목표는 매 판 같다. 시드는 상태를 초기화하며 목표를 변형하지 않는다. 완성 판정은 투영 마스크의 겹침 비율 97.5% 이상으로 한다. 여러 조작 순서와 동일한 실루엣은 인정하지만 교육적 의미가 다른 모든 조합을 평가하는 장치는 아니다.

## 검증과 다음 관찰

[18번 분석](18-전체맵-게임성-분석.md)에서 확인한 게임성 과제는 단순 도형·발판 왕복 반복, 문 열림에 머무는 공연 보상, 마지막 무대가 거리·회전까지 종합하지 않는 점이다. 후속 조정에는 [19번 기준](19-게임성-반영-기준.md)을 적용하고 그림자가 실제 공연 장면을 완성하는 결과를 검토한다. 현재는 개선 후보이며 첫 버전에 구현하지 않았다.

- 새 맵 시험 55건: 거리·회전 투영, 실제 Three.js 모형 꼭짓점과 계산의 일치, 오답·완성·재실험·초기화, 학생별 독립 선택, 거리 제한, 발판 연속 입력 방지.
- 세 시드에서 실제 이동 봇이 네 무대의 조작 발판을 밟고 문을 통과해 결승에 도착했다.
- 전체 시험 948건 통과. 브라우저 개발 검증 화면에서 크기·회전·위치·조합 표시와 완성 동작을 확인했다.
- iPad 글꼴·터치·FPS, 실제 학급 방의 재접속, 재미·학습 효과는 미확인이다.

교실에서는 학생이 바뀐 그림자를 보고 다음 선택을 수정하는지, 거리와 회전을 이유로 설명하는지, 친구가 답만 알려주는지 원리를 설명하는지 관찰한다. 단순 발판 횟수 암기가 되는지도 확인한다. 수업 후에는 “빛과 화면을 그대로 두고 물체를 빛 쪽으로 옮기면 왜 그림자가 커졌나요?”를 묻는다.

실행: 혼자 연습하기 → 물리 → 그림자 변신 극장. 개발용 주소 `?map=shadowtheater`. 시각 검증 페이지는 `prototype/tests/shadowtheater-visual.html`이며 실제 맵의 발판 입력으로 결과를 바꾼다.

공통 `kit.js`, `main.js`, Firebase 필드는 변경하지 않았다. 새 파일은 `shadowtheater.js`, `shadow-math.js`, 전용 시험·시각 검증 페이지이며 `levels/index.js`에 맵을 등록했다.
