# 32. 점프 연구소 시소 안전 길과 태양계 달 높이뛰기 (선택 활동)

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: [18](18-전체맵-게임성-분석.md) 1번(시소 안전 선택 경로)·2번(큰 점프·낮은 점프를 이용하는 선택 도전), [19](19-게임성-반영-기준.md), [31](31-점프연구소-시험코스.md)
- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.**

## 1. 점프 연구소: 시소 안전 길 (선택)

- **현재(코드)**: 시소 다리는 올라탄 모든 학생의 위치로 기울어, 내가 밀치지 않아도 다른 학생 때문에 떨어질 수 있다(`docs/18` 위험).
- **추가**: 체크포인트 '시소 다리 앞' 서쪽에서 시험장 입구까지 이어지는 **폭 1.8m 외길**(길이 약 36m, 쉬는 칸 2곳). 다른 학생의 위치에 영향을 받지 않는다. 대신 좁아서 정밀한 걷기가 필요하다. 가운데 시소 길은 그대로다. 안내판 "안전한 외길 (선택)".
- 시험(`tests/lab.mjs`): 외길로 시험 구간 입구까지, 점프 없이도 곧게 통과.
- 점검표 요약: 선택 = 시소(빠르지만 친구 위치에 흔들림) 대 외길(안정적이지만 좁고 김). 재시도 = 외길에서 떨어지면 '시소 다리 앞' 체크포인트로. 한계 = 외길이 시소보다 오래 걸려 실제로 고르는지는 관찰 필요. 시소 자체의 혼잡은 바뀌지 않았다.

## 2. 태양계: 달 높이뛰기 탑 (선택)

- **현재(코드)**: 중력은 구역마다 다르지만 학생이 그 차이를 이용해 길을 고르는 곳은 별(거리) 정도다.
- **추가**: 달 구역 평원 옆에 한 칸 +4.5m 높이의 계단 3칸(높이 13.5→18→22.5)과 꼭대기 도전 별. 지구 점프 높이는 약 1.9m, 달 중력(게임 ×0.33)에서는 약 5.6m라서 달에서만 오를 수 있다. 안내판 "달 높이뛰기 (선택)".
  - 평원에 체크포인트 **'달 평원'**을 추가했다(떨어져도 달 도착 지점까지 되돌아가지 않는다). 안 올라가도 기본 길은 이어진다.
  - 시험(`tests/solar-gates.mjs`): 달 평원에서 꼭대기 별까지 통과, 별 획득, 같은 계단을 지구 중력(×1)으로는 오르지 못함(중력 차이가 실제로 영향을 줌).
- 과학 범위: 달의 중력이 지구보다 약해 더 높이 뛴다(기존 해설과 같음). 게임 중력 ×0.33은 조작용이라는 기존 안내(`info` 판)가 이 구역에 적용된다. 수치 계산은 하지 않는다.
- 점검표 요약: 핵심 재미 = 중력 차이를 몸으로 이용해 높이 오르기. 선택 = 오를지 말지, 성공 위치·타이밍. 즉시 결과 = 같은 점프가 달에서만 닿는다. 재시도 = 달 평원 체크포인트. 기본 완주·선택 = 안내판 표시, 건너뛰어도 길 이어짐. 근거 = 코드·시험(규칙·이동). 재미는 미확인.
- 한계: 달에서 4.5m를 오르려면 점프 타이밍과 이동 거리 맞추기가 필요해 터치 조작에서 어려울 수 있다. 어렵다는 관찰이 나오면 칸 높이를 3.5~4m로 낮춘다. 목성의 낮은 점프를 이용하는 선택 활동은 아직 없다(후속 후보).

## 교실에서 볼 장면 ([12](12-교실-시험-관찰지.md)에 추가)

1. 시소와 외길 중 어느 쪽을 고르는지, 친구가 시소에 여럿 올라 있을 때 외길로 바꾸는지.
2. 외길에서 떨어지는 빈도, 쉬는 칸을 쓰는지.
3. 달 높이뛰기 탑을 시도하는 비율, 몇 번 만에 오르는지, "달이라서 높이 뛴다"고 말하는지.
4. 탑에서 떨어진 학생이 '달 평원'에서 바로 다시 도전하는지 포기하는지.
