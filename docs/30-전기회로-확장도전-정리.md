# 30. 전기 회로 공장: 확장 도전 안내와 통과 조건 정리

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: [18](18-전체맵-게임성-분석.md) 전기 회로 위험("`확장 도전`이라는 안내가 붙어도 문은 주 경로에 있어 선택 활동으로 볼 수 없다", "후반의 밝기 문은 실제 회로 조작의 즐거움을 퀴즈로 바꾼다"), [19](19-게임성-반영-기준.md), [10](10-과학표현-협동-수정.md)
- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.**

## 불일치 확인 (코드)

- 후반 예측 문 두 개(`[확장 도전] 같은 전구 두 개를 더 밝게…`, `하나를 빼도 켜져 있는 연결은?`)는 안내판이 "확장 도전"이라고 했지만 문 양옆이 벽 날개와 발판 폭 14m로 막혀 있어 **반드시 통과해야 하는 경로**였다. 틀린 문은 떨어진다. 선택이라고 읽히는 이름과 필수 조건이 달랐다.
- 문제 자체는 스위치를 밟아 문을 여는 앞 구간(직렬·병렬 논리)에서 해 본 행동이 아니라 "전구 밝기"라는 별도 지식이어서, 학생이 만져 본 적 없는 내용을 퀴즈로만 물었다([10](10-과학표현-협동-수정.md)에서 "밝기를 보여 주는 장치는 추가하지 않았다"고 기록한 부분).

## 바뀐 것

1. **확장 도전을 실제 선택으로**: 두 예측 문 양옆(`x ±20`)에 건너뛰는 길을 놓았다. 문 앞·뒤 발판을 44m 폭으로 넓히고 문 옆 통로 발판을 이었다. 안내판은 "확장 도전 (선택) / 전구 밝기 · 같은 전구·같은 전지 / 문이 어려우면 양옆 길로 가요"로 바꿨다. 문 자체(정답 문 통과, 틀린 문 낙하)와 문제·정답은 그대로다.
2. **밝기 실험대**(모형, 선택): 예측 문 앞 왼쪽에 발판 3개(직렬로 연결·병렬로 연결·전구 B 빼기)와 전구 3개(기준 전구 1개, 전구 A·B)를 놓았다.
   - 직렬을 고르면 A·B가 기준보다 어둡게, 병렬을 고르면 기준과 같은 밝기로 켜진다. 전구 B를 빼면 직렬은 A도 꺼지고 병렬은 A가 켜져 있다.
   - 안내판: "전구 밝기 실험대 (모형) / 같은 전지·같은 전구 · 관찰 n / 4". 관찰 4가지 = 직렬·병렬 보기, 직렬에서 빼기, 병렬에서 빼기.
   - 예측 문 힌트에 "왼쪽 밝기 실험대에서 확인할 수 있어요"를 더했다.
   - 상태는 학생별이다(방에 따로 전송하지 않는다).
3. 시험(`tests/coop.mjs`, 12건 추가): 왼쪽·오른쪽 건너뛰기 길로 결승까지 도달, 실험대 초기 상태·직렬(어둡고 켜짐)·병렬(기준과 같음)·병렬에서 빼기(남은 전구 켜짐)·직렬에서 빼기(모두 꺼짐)·진행 초기화. 기존 협동 시험 11건 그대로.
4. 공통 파일 변경: 없음. `variants.js`의 `dynamicSign`을 가져다 썼다.

## 과학 범위와 모형 표시

- 표현하는 것: 같은 전지·같은 전구 두 개를 직렬로 이으면 전구 하나일 때보다 어둡고, 병렬은 전구 하나일 때와 같다는 이상적인 모형. 직렬에서 하나를 빼면 회로가 끊기고 병렬은 나머지가 켜져 있다. 기존 문제 해설과 같은 내용이다.
- 밝기 값(어두움 0.35, 기준 0.9)은 화면 표현이며 실제 밝기 수치가 아니다. 실제 전구·전지는 조금씩 달라 정확히 같지 않다. 안내판에 "모형"과 "같은 전지·같은 전구"를 적었다.
- 쓰지 않은 것: 옴의 법칙, 전류·전압 값, 직렬·병렬 전구의 정확한 밝기 비율.

## 한계와 후속

- 직렬 문에서 기다리는 학생이 쓸 만한 활동은 아직 직렬 문 근처에 없다(실험대는 후반에 있다). 대기·역할 교대를 먼저 관찰한 뒤 실험대를 직렬 문 앞으로 옮길지 정한다([18](18-전체맵-게임성-분석.md) 개선 방향 첫 문장).
- 건너뛰기 길을 택하면 틀린 문에서 떨어지는 경험도, 정답 해설도 보지 못한다. 선택이므로 허용한다. 학습 확인은 실험대와 문 두 곳에서만 일어난다.
- 문 앞뒤 발판을 넓혀 시야에 빈 공간이 늘었다. 카메라와 안내판 위치는 화면 확인 전이다.
- 건너뛰기 길은 문 한 개마다 좌우 두 곳이다. 21명 방에서 혼잡한지는 관찰 항목이다.

## 교실에서 볼 장면 ([12](12-교실-시험-관찰지.md)에 추가)

1. 실험대를 쓰는 학생의 비율, 직렬·병렬·빼기를 모두 해 보는지, 전구 밝기 차이를 말로 설명하는지.
2. 예측 문에서 정답 문을 고르는 학생과 건너뛰기 길로 가는 학생의 비율. 건너뛰기를 택한 이유.
3. 실험대를 해 본 학생이 예측 문 정답을 더 빨리 고르는지(인과로 단정하지 않기).
4. 문 앞에서 학생이 헤매는지, 실험대와 문 사이 이동이 어색한지.
