## 발견 사항

### G1. 거대 실험실: 구간 이름 "액체 높이"와 내용(부력)이 다르다
- **근거(코드)**: 구간명 `액체 높이 실험`(`giantlab.js:23`), 안내판 제목 `액체 높이`, 안내문과 문제는 "물이 물체를 위로 밀어 올리는 힘 = 부력". 움직이는 발판은 물높이에 맞춰 오르내리지만 학생이 무엇을 바꿔도 달라지지 않는다.
- **영향**: 학생이 "액체 높이"를 부력과 별개로 이해하거나, 발판이 오르내리는 것을 부력의 증거로 읽을 수 있다. 발판은 물 위에 떠 있는 것처럼 보이지만 "왜 뜨는지"를 판단할 단서가 없다 `[추론]`.
- **조치 방향**: 이름을 `부력과 뜨는 발판`으로 바꾼다. 구간명은 저장된 진행 기록 표시와 맵 메타 시험에 쓰이므로 이름 변경 때 `tests/giantlab.mjs`·진행 표시 영향을 확인한다. 게임성 보강(`docs/14` 2번)과 함께 처리하는 것이 효율적이다.

### W1. 물의 순환: 응결 문제 오답 "바로 얼어 눈이 됨"
- **근거(코드)**: `water.js:79`. 구름 안내판은 "얼음 알갱이"를 언급한다.
- **영향**: 수증기가 바로 얼음이 되는 현상(승화의 반대)은 실제로 있어서, 오답이 완전히 틀린 말은 아니다. 질문이 "물방울이 되는 현상"이라 정답은 분명하지만 선택지가 오해를 줄 수 있다.
- **조치 방향**: 오답을 "비가 되어 떨어짐"처럼 순환의 다른 단계로 바꾸면 단계 구분 연습이 된다. 필수 수정은 아니다.

### G2. 거대 실험실: 학생의 선택이 없다 (게임성)
- **근거(코드)**: 피스톤 발판과 물높이 발판은 학생과 무관하게 움직인다. 개념 판단은 문항 3개(안전·부피·부력)뿐이다. `docs/18`의 "발판 조작 → 확인 → 문 열기"와는 달리 조작조차 없어 관찰만 한다.
- **조치 방향**: `docs/14` 2번(누르는 힘 선택 → 부피 도식 변화 → 목표 부피로 문 열기)을 구현한다. 과학 범위는 "같은 양의 공기를 누르면 부피가 줄어든다"까지로 제한한다.
