# 16. 새로운 맵 아이디어 — 미술 공방 관찰 이후

2026-10-01. 구상 당시 11개 맵과 다른 선택 경험을 만들고, 학생 20명 미술 공방 관찰의 '생각 → 선택 → 결과 확인 → 다음 사고·행동'을 설계 기준으로 삼았다. 그림자 변신 극장은 첫 버전을 구현했으며 나머지는 아이디어 단계다. 새 맵의 학습 효과·개발 비용은 검증하지 않았다.

공통 방향: 학생별 장치, 즉시 보이는 결과, 수정 가능한 선택, 체크포인트·탈락 없음, 자발적 도움, 선택 도전. 정밀 조작·필수 동시 협동·학생 간 밀치기나 잡기를 요구하지 않는다. 목표 변형은 원리를 유지하는 범위에서 후속 검토한다.

## 후보 비교

후속 제작에는 [18. 게임성 분석](18-전체맵-게임성-분석.md)과 [19. 적용 기준](19-게임성-반영-기준.md)을 반영한다. 특히 로봇의 명령 결과는 실제 배송·도시 변화에, 얼음의 포장·경로 선택은 화물 상태와 도착 결과에 이어져야 한다. 설계·제작 기록에 게임성 점검표를 포함하고 실험판·문 구조의 반복을 점검한다.

## 우선 추천 1. 그림자 변신 극장

첫 버전 제작 완료: [17. 그림자 변신 극장 제작](17-그림자변신극장-제작.md). 아래는 최초 구상이며 구현 범위와 검증 결과는 제작 기록을 따른다.

- 배경: 불이 꺼진 극장에서 그림자 공연으로 무대를 복구한다.
- 첫 구간: 빛·물체·화면을 보고 조명을 켜며 그림자의 위치를 확인한다.
- 둘째: 고정된 화면과 작은 광원을 기준으로 물체를 앞뒤로 이동해 목표 크기를 맞춘다.
- 셋째: 물체 방향을 돌려 정면·옆면 실루엣을 비교하고 목표 모양을 만든다.
- 마지막: 두 물체의 그림자를 조합한다. 목표가 허용하는 여러 조합을 인정하는 방향을 검토한다.
- 예상 대화: '물체를 빛 쪽으로 더 옮겨 보자', '옆으로 돌리면 모양이 달라져'. 이는 예상이며 아직 교실에서 관찰하지 않았다.
- 과학과 게임 구분: 그림자는 물체가 빛을 가려 생긴다. 그림자가 물리적인 다리가 되는 연출을 쓰면 게임 장치라고 표시한다. 같은 고정 화면·광원 조건에서 거리의 효과를 비교하고, 태양빛과 가까운 광원의 조건을 섞지 않는다.
- 초기 범위: 작은 광원 하나·정적 물체·화면 하나. 계산한 투영 도형과 판단을 일치시키고 GPU 그림자 모양만 정답 판정으로 사용하지 않는다. 움직이는 조명·여러 광원·색 그림자는 후속이다.

거리·빛·물체의 변수를 바꾸는 체험 근거: [Science World — Light and Shadows](https://www.scienceworld.ca/resource/light-and-shadows/), [Ontario Science Centre — Shadow Play](https://www.ontariosciencecentre.ca/science-at-home/diy-science-fun/summer-rays-and-shadow-play).

## 우선 추천 2. 명령 택배 로봇 도시

- 배경: 끊어진 도시의 배송로를 학생이 작은 배송 로봇의 명령으로 복구한다.
- 선택: 앞으로 이동·왼쪽/오른쪽 회전·반복 횟수를 발판으로 지정한다. 물체 잡기나 글자 코딩은 요구하지 않는다.
- 결과: 실행하면 로봇이 명령을 한 단계씩 따라가고, 현재 명령과 지나온 길이 보인다. 학생은 잘못 돌아간 지점을 찾아 명령을 바꾸고 다시 실행한다.
- 연결: 배송 성공 후 학생이 건너갈 이동 발판이나 통로가 켜진다. 장치 상태는 개인별이며 친구는 경로를 보며 조언할 수 있다.
- 구간: 짧은 경로 → 회전 → 반복되는 길 → 두 가지 이상 성공하는 배송 경로.
- 보상: 최단 명령은 선택 도전. 긴 명령이어도 배송에 성공하면 완주를 허용한다. 실패는 로봇을 출발점으로 되돌려 수정하고 학생을 떨어뜨리지 않는다.
- 판단 기준: 실행하기 전에 다음 도착 지점을 설명하는가, 실행 결과로 오류 위치를 고치는가. 코딩 언어 문법 정답을 묻지 않는다.

## 우선 추천 3. 열을 지키는 얼음 택배

- 배경: 따뜻한 마을을 지나 얼음 소품을 공연장에 배달한다.
- 선택: 포장 재료와 그늘·햇빛 경로를 바꾼다. 같은 조건에서 하나씩 바꾸며 비교한다.
- 결과: 시험 공간에서는 똑같은 게임 시간을 적용해 포장별 변화가 나란히 보인다. 배송 길에서는 현재 온도·녹는 상태를 그림과 숫자로 보여 준다.
- 복구: 너무 많이 녹았으면 가까운 재포장 지점에서 새 얼음으로 다시 시도한다. 탈락·급한 조작·필수 대기는 없다.
- 과학 범위: 단열은 열 이동을 줄이는 것이며 '차가움이 밖으로 샌다'고 쓰지 않는다. 재료·온도·변화 속도는 단순 모형으로 표시하고 실제 재료의 성능 순위를 임의로 확정하지 않는다.
- 먼저 고정된 시험 시간으로 재료 차이가 보이는지 확인한다. 자유 배송에서는 시간·경로·포장 변수가 섞이므로 재료만의 효과로 해석하지 않는다.

열 이동과 단열 표현 근거: [미국 에너지부 — Heat Flow](https://bsesc.energy.gov/energy-basics/heat-flow).

## 후속 후보의 조건

- 메아리 탐정단: 실제 음성과 함께 되돌아오는 신호를 시각화해 소리를 끈 교실에서도 가능하게 한다. 메아리의 반사·왕복 시간을 다루며 실제 음파를 벽에 단순 광선처럼만 설명하지 않는다. [Exploratorium — Rotunda Echo](https://annex.exploratorium.edu/xref/exhibits/rotunda_echo.html).
- 자석 항구: 모든 금속이 자석에 붙는 것으로 표현하지 않고 철 화물로 범위를 좁힌다. 힘·거리·자세와 물리 충돌을 새로 검증해야 한다.
- 씨앗 구조대: 식물·생태계의 반응을 일반 법칙처럼 단정하지 않고 종·조건을 제한한다. 기다리는 시간을 게임에서 축약한다.
- 문장 구조 열차: 한 정답만 강제하기보다 문장에 따라 달라지는 장면을 보여 준다. 조사·맥락·복수의 자연스러운 문장을 평가하는 범위가 먼저 정해져야 한다.

사용자가 세 우선 후보의 제작 시작을 요청해 그림자 변신 극장 첫 버전을 완성했다. 다음 제작 순서는 명령 택배 로봇 도시, 열을 지키는 얼음 택배이며 아직 구현하지 않았다. 기존 맵 수정은 Claude, 새 맵은 Codex 담당을 유지한다.
