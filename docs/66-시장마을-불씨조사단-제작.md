## 1. 증거와 자유 순서

어떤 두 장소든 흔적과 장부로 주원인·물체를 교차 확인한다. 각 장소의 흔적에는 가능한 출발 표식 두 개가 남고, 다른 현장의 흔적과 공통인 표식이 하나다. 장부의 배치표와 대조하면 물체를 특정한다. 잔열·번진 마른 물건·바람 통로 자국을 물체와 함께 읽어 주된 조건을 판단한다. 숫자 답을 옮겨 적는 문제는 아니다. 표식 순서와 배치는 시드로 섞어 첫 번째 표식이 항상 답인 편법을 막았다.

객주의 착각 증언은 다른 현장에서 출처를 밝힌 전달 증언으로도 얻는다. 객주에서는 당일 장부를 바로 옆에서 읽어 반박할 수 있다. 아침에 본 빈 모습에서 저녁까지 반입이 없었다고 착각하지만 장부에는 오늘 오후 반입이 있다. 사람 이름 세 가지가 바뀌며, 첫 축소 버전의 착각 유형은 이 시간 착각 하나다(전체 조합 구현 아님).

모든 장소에 장부 반입 물건(갈색·단단한 장작)과 같은 끈이 남은 검고 잘 부서지는 숯·재 비교 쌍을 둔다. 원본과 사본은 서로 독립된 증거로 과장하지 않는다. 현장의 흔적은 서로 다른 관찰이고, 창고·대장간 장부는 객주 기록의 사본이라고 표시한다.

한 장소의 흔적+장부로는 물체 후보가 두 개 남는다. 두 장소의 흔적 두 장과 장부 한 장이면 N=3·2종류로 확정 가능하다. 한 장소의 카드 세 종류로 불확실한 결론을 제출하는 것도 허용한다. 최소 입장량과 충분한 판단 근거를 같은 것으로 취급하지 않는다.

자유 순서는 조사 현장에 적용한다. 조사량과 결론 제출 뒤 복구에 들어가며, 결론 정오는 입장을 막지 않는다. 실제 사건은 제출 답에 따라 변하지 않는다. 증거 해석을 바탕으로 도구를 고르고 그 도구의 운반·처리 결과를 다음 이동에 사용한다. 이는 [58](58-등고선-지형탐험대-제작-계획.md) 10절의 결과를 쓰지 않아도 끝나는 문제를 피하기 위한 구조다.

## 2. 계획과 측정

### 2.1 계획 숫자와 측정 방법

- **계획:** 적합 대응이 나머지 각각보다 **10m 이상·15% 이상** 짧음, 시간도 짧음. 완성판 길이 150~250m와 15~25분은 계획서의 목표다. 축소판에서 이를 모두 달성했다고 주장하지 않는다.
- **측정:** `tests/harness.mjs`의 `run(...)`이 생성한 Player 인스턴스의 step을 전용 시험에서 감싸 실제 매 tick XZ 변위를 누적했다(1/120초). 공용 harness/player는 변경하지 않았다. 낙하·막힘은 실패이며 부활·순간이동으로 이어 붙이지 않는다.
- **공정성:** 실제 조작·보급·작업·결승 위치만 필수 목표로 삼고, 나머지 조작 발판을 실수로 밟지 않는 최단 visibility graph를 모든 대응에 같은 방식으로 적용한다. 임의 우회 waypoint나 대응별 속도·대기 보정은 없다. 도착 반경은 모두 공용 run의 0.6m, 걷기만 하며 점프하지 않는다. 같은 줄의 조사·제출까지 거리·시간 동일성도 검사한다.
- **경계:** 대응 비교는 본부 제출이 실제 수락된 물리 tick부터 동일 결승 목표 도착까지다. 도구 선택 발판으로 가는 거리, 우물·멍석·바구니/수레 보급, 왕복과 작업을 모두 포함한다. 결론 선택 전 조사 거리는 별도 표에 둔다.
- **시간의 한계:** 아래 초는 멈추지 않고 걷는 봇의 시뮬레이션 시간이다. 증거 읽기·추론·대화가 없으므로 수업 소요 시간이나 재미의 지표가 아니다.

### 2.2 주된 원인 × 대응 3×3 실측

각 칸은 **수평 이동거리 m / 시뮬레이션 초**다. 굵은 칸이 현장에 적합한 대응이다. 같은 줄은 같은 시드·동일 증거 경로·동일 결론 제출 상태다.

| 사건 주원인(시드) | 물로 식히기 | 젖은 멍석 덮기 | 탈 물질 치우기 |
|---|---:|---:|---:|
| 열 (7) | **71.62 / 10.46** | 110.70 / 16.63 | 133.90 / 19.77 |
| 탈 물질 (1) | 133.94 / 19.80 | 110.64 / 16.61 | **71.45 / 10.40** |
| 공기 (2) | 134.26 / 19.83 | **61.17 / 8.88** | 134.03 / 19.81 |

가장 작은 차이도 약 **39.09m·35.3%**다(열: 물 대 덮기). 구현 전 10m·15% 기준을 모두 충족한다. 각 원인의 다른 세부 물체까지 6사건 × 3대응을 추가로 걸어 같은 기준을 확인했다. 모든 대응은 완주 가능하다.

**효율 차이를 만든 게임 모형:** 열 사건에는 연결 수로 물수레, 탈 물질 사건에는 연결 짚단용 손수레, 공기 사건에는 이어진 통로용 긴 젖은 멍석을 배치한다. 이 도구는 세 작업 지점을 연속 처리하고, 다른 도구는 한 작업 뒤 입구 보급 위치로 돌아간다. 우물과 치우기 도구는 좌우, 멍석은 가운데라 운반 거리도 다르다. 정답 제출 여부가 이 배치나 처리량을 바꾸지는 않는다. 이것은 현장 도구·배치를 단순화한 **게임 규칙**이며, 실제 모든 화재에서 주원인과 동일한 조건을 제거해야 가장 효율적이라는 과학 법칙이 아니다. 세 소화 원리는 모두 인정한다. 교실에서 이 구별과 반복 운반 부담을 확인해야 한다.

### 2.3 출발~결승 전체 실측

대표 최소 카드 경로는 창고 흔적·장부 → 대장간 흔적 → 결론 두 칸 → 제출이다. 조사·선택·제출까지의 물체 보기 이동량은 사건에 따라 다르다. 같은 사건 안에서는 세 대응 모두 같은 출발 상태다.

| 주원인 | 조사·결론 제출까지 m / 초 | 적합 대응 포함 전체 m / 초 | 비효율 대응 포함 전체 m 범위 |
|---|---:|---:|---:|
| 열 | 130.53 / 19.05 | 202.15 / 29.51 | 241.24~264.43 |
| 탈 물질 | 121.24 / 17.73 | 192.69 / 28.13 | 231.88~255.18 |
| 공기 | 117.86 / 17.24 | 179.03 / 26.12 | 251.88~252.12 |

비효율 대응의 250m 초과는 숨기지 않는다. 완성판 확장 전에 보급 위치·운반량·왕복 부담을 교사 시연에서 점검할 후보로 둔다. 위 표는 목표 길이를 계산한 값이 아니라 실제 봇 궤적이다.

### 2.4 틀린 결론 뒤 복귀·재결론 실측

첫 작업을 비효율 대응으로 마친 뒤 이미 안전해진 길로 돌아온다. 복귀 경계는 결론 제출 발판 앞 **본부 입구 z=-20.4**다. 그 뒤 두 결론 칸을 실제로 다시 밟아 수정·재제출한다. 기존 복구는 유지된다.

| 실제 주원인(시드) | 본부 입구까지 m / 초 | 두 칸 수정·재제출 m / 초 | 합계 m / 초 |
|---|---:|---:|---:|
| 열 (7) | 16.97 / 2.48 | 35.89 / 5.33 | 52.87 / 7.82 |
| 탈 물질 (1) | 16.96 / 2.53 | 35.93 / 5.29 | 52.88 / 7.83 |
| 공기 (2) | 16.96 / 2.53 | 32.76 / 4.81 | 49.72 / 7.34 |

위 수정 시간에도 증거 재독·고민은 들어 있지 않다. 교실에서 재선택 발판 왕복이 부담이면 결론 입력 배치를 줄인다. 착각 증언을 다시 조사하도록 강제하지 않는다.

### 2.5 재현·시험 범위

- 전용 시험: `prototype/tests/marketfire.mjs`. 시드 **1~12, 14**(13개), 현장 3쌍 × 양방향 순서 = **78개 실제 수집 동선**에서 주원인·물체 확정, 착각 증언 반박, 연소 전후 쌍 확보를 검사했다.
- 같은 13시드 × 현장 3쌍 = **39개 최소 3장 완주 동선**. 결론은 조사 예정 카드의 정보로 도출하고, 실제 걷기 수집 결과와 대조한다. 한 종류만 수집·카드 중복 왕복으로 입장량을 채우는 시도는 거부한다.
- 별 없이 기본 완주, 두 별 도달, 틀린 결론의 입장 허용·모순 표시·복귀·재제출·완주, resetProgress/setSeed의 카드·길·별 복원을 검사했다.
- 원자료: [marketfire-measurements.json](../prototype/tests/marketfire-measurements.json). `node tests/marketfire.mjs --write-measurements`로 성공 시에만 갱신한다. 일반 실행은 저장한 측정치와 재측정의 일치도 검사한다. 수치를 바꾸면 이 문서 표도 함께 갱신한다.
- 최종 `prototype`의 **`npm test` 전체 통과**(종료 코드 0). 새 맵 전용 시험 **569 통과 / 0 실패**, maps-meta 97 / 0, map-rules 86 / 0, 등록 호환 비교 44배치 동일이다. 기존 시험도 모두 통과했다. `git diff --check`도 통과했다.
- 실제 Chrome에서 화학 분류 등록·연습 시작·시작 지점 화면과 짧은 키 이동을 확인했다. 전체 브라우저 완주, 수첩의 모든 카드 실제 조작, iPad 터치, 교사 보고·교실 검증은 **미확인**이다.

## 5. 변경 범위와 호환 영향

맵·전용 시험 추가, 등록 목록·npm 시험 목록·두 README·55 색인을 갱신했다. 기존 미커밋 physics/player/main 및 보관한 미끄럼 협곡은 이 작업에서 수정하지 않았다. 동시에 작성된 자유 탐험 맵의 64·65·67 문서와 색인의 해당 행도 유지한다.

**안전 근거(실행 단계):** `tests/marketfire-registration.mjs`는 현재 index에서 새 맵 import·등록 두 행만 뺀 목록을 재구성하고, 기존 22항목 × 시드 3·17의 출발점·체크포인트·별·충돌체 크기/행렬/상태가 현재 등록 목록과 같은지 비교했다(**44 배치 동일**). 기준선을 두 번 만들어 재현성을 확인하고, 출발점을 의도적으로 바꾼 비교가 불일치를 잡는지도 검사했다. UUID는 비교하지 않는다. 이는 기존 미커밋 물리 변경 이전의 HEAD와 비교한 결과는 아니다.

등록 호환성은 maps-meta·map-rules·전체 npm test로도 확인한다. 새 `marketfire` id를 모르는 구 버전 클라이언트는 기본 맵으로 대체하므로, 같은 반에서 사용할 때 브라우저를 같은 코드로 새로고침해야 한다(코드 기반 추론). 실제 기기 간 같은 방 동기화는 미확인이다. 수첩 DOM은 맵 dispose 때 제거하고 카드 상태·도구·복구는 레벨 인스턴스에만 둔다. 서버 데이터 필드·별 상한·교사 API는 바꾸지 않았다.

## 6. 교육 표현 대조와 한계

- 성취기준 코드는 계획서의 **사용자 제공 문장**을 따른다. NCIC의 [2022 자료 목록](https://www.ncic.re.kr/bbs/eduNotice2022/list.do)은 열렸으나 원문 안내 상세 페이지가 404여서 NCIC 원문 대조를 완료하지 못했다. `[6과14-02·03]`을 화면이나 교사 UI에 표시하지 않으며, 사회 성취기준 대응은 주장하지 않는다.
- 소화 표현은 [경기도교육청 공개 연소·소화 수업 협의 자료](https://www.goe.go.kr/resource/goe/na/bbs_1937/2025/05/7ef5f59e-0156-4fd8-9277-4fc8a75d97d0.pdf) 8쪽에서 연소 세 조건과 산소 차단·탈 물질 제거·발화점 미만 냉각을 대조했다. 출판사 공개 자료 검색 문구도 일치했지만 교과서 본문 파일 직접 대조는 미완료다.
- 흔적·장부는 가상 모형 자료다. 재·숯의 색과 부서짐은 전후 비교의 출발점이며, 실제 실험이나 모든 연소 생성물 확인을 대신하지 않는다. 기름 화재·환경 피해·실제 역사 사실은 첫 버전에 넣지 않았다.
- 코드·자동 시험은 규칙·실제 이동·측정의 근거다. 학생의 증거 해석, 재미, 학습 효과와 수업 소요 시간은 교사·교실 관찰을 기다린다.
