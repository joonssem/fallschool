## 2. 이날 확인한 것

- **시험이 통과해도 계획 숫자가 틀릴 수 있다.** 등고선 지형 탐험대의 길이 "170~220m"는 손으로 더한 계획값이었다. 봇이 걸은 거리를 재자 246·250·265m였다. 새 맵의 시험은 가능하면 걸은 값을 재야 한다.
- **자유 순서와 결과 사용은 충돌한다.** 어느 구역이든 직접 갈 수 있으면 결과가 다음 이동에 쓰이지 않는다. 입구를 결과로 열게 해 해결했다([58](58-등고선-지형탐험대-제작-계획.md) 10.1).
- **작업 파일 혼입 주의.** `git add -A`는 다른 에이전트의 작업 중 파일까지 올린다(57번 초안이 같이 커밋됨). 담당이 다른 파일은 경로를 지정해 커밋한다.
- 재부팅 뒤에도 작업 파일은 남아 있었고, 전체 시험이 통과했다.
