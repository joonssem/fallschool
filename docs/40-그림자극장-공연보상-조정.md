# 그림자 극장 공연 보상 조정

2026-10-02. [18번 전체 맵 게임성 분석](18-전체맵-게임성-분석.md)은 첫 그림자 극장의 약점으로 문 열림에 머무는 공연 보상과, 앞 무대의 판단이 마지막에 모이지 않는 점을 기록했다. [19번 적용 기준](19-게임성-반영-기준.md)의 맵별 Codex 후속 후보에 따라 마지막 커튼콜을 조정했다. 첫 버전 구조와 교실 관찰 근거는 [17번 제작 기록](17-그림자변신극장-제작.md)을 유지한다.

## 바뀐 보상

무대에서 `공연 완성`을 누르면 실제 조작해 목표에 맞춘 물체 배치를 별도 사본으로 저장한다. 마지막 커튼콜의 네 칸 포스터가 1막 크기, 2막 방향, 3막 자리, 4막 물체 조합 결과를 차례로 보여 준다. 아직 끝내지 않은 장면은 빈 무대로 표시되고 완성 수가 갱신된다. 네 무대가 끝나면 포스터 제목·하단 문구도 완성 공연에 맞게 바뀌며 네 조명 장식이 천천히 밝기를 바꾼다.

한 방에서 결과를 본 뒤 `처음 모양`으로 재실험해도 통과 길과 커튼콜에 저장한 그림자는 유지된다. 새 경기·처음부터 시작은 기존 초기화 흐름으로 네 장면을 모두 초기화한다. 기본 완주, 네 무대의 목표·조작, 선택 도전 별은 바꾸지 않았다. 장식은 맵 충돌체에 추가하지 않아 실제 플레이 경로에 영향을 주지 않는다.

## 19번 점검표

| 항목 | 후속 조정 |
|---|---|
| 핵심 재미 | 네 가지 그림자 조작의 결과로 마지막 공연을 완성한다. 교실 재미는 미확인. |
| 의미 있는 선택 | 크기·방향·자리·물체 선택이 각자 완성한 실루엣으로 남는다. |
| 즉시 결과 | 무대를 완성하면 커튼콜 포스터의 해당 칸에 실제 실루엣과 완성 표시가 나타난다. |
| 다음 행동·성취 | 네 결과가 한 공연 포스터가 되고 완주 장면으로 이어진다. |
| 구간 변화 | 기존 네 무대의 조작은 그대로다. 새 퍼즐이나 발판 왕복을 추가하지 않았다. |
| 재시도 부담 | 무대 안 재실험은 저장 보상과 길을 유지한다. 새 경기 초기화는 네 장면을 지운다. |
| 기본 완주·선택 도전 | 기존 네 무대 완주가 기본 경로, 도전 별은 계속 선택이다. |
| 친구와의 연결 | 공연 포스터를 설명할 소재가 생기지만 강제 협동은 없다. 도움 방식은 관찰 필요. |
| 재체험 용도 | 고정 목표의 첫 체험용을 유지한다. 새 판단이 추가된 반복 모드는 아니다. |
| 근거·관찰 | 자동 시험은 캡처·보존·초기화·이동 규칙만 확인한다. 시각 매력·학습 효과는 교실에서 확인한다. |

## 변경 범위와 검증

수정 파일은 `prototype/src/levels/shadowtheater.js`와 `prototype/tests/shadowtheater.mjs`다. 공용 맵 등록, 물리, 다른 맵, Firebase 계약은 변경하지 않았다. 포스터는 게임 내 CanvasTexture로 만들고 완료한 실제 프레임의 투영 윤곽을 그린다. 장식용 무대 프레임은 충돌 없는 Three.js 메시로 두어 이동을 막지 않는다.

전용 시험은 네 방에서 결과 저장, 재실험 뒤 보존, 네 결과를 모은 완성 상태, 새 경기 초기화를 검사하고 세 시드에서 실제 이동 봇이 완주하는지 확인한다. 현재 브라우저 화면·iPad 레이아웃·성능·재접속 저장은 확인하지 않았다.

교실에서는 본인이 만든 각 그림자를 커튼콜에서 알아보는지, 네 장면의 조작 차이를 설명하는지, 마지막 포스터가 완주 성취를 높이는지 관찰한다. 사후 질문은 “마지막 공연의 네 장면은 앞 무대에서 무엇을 바꿔서 만들었나요?”로 한다. 첫 체험과 같은 반 재체험을 나눠 기록한다.
