# 03. 학교 환경 조건

- 문서 상태: 1차 확인
- 작성일: 2026-09-28
- 관련 문서: [01. 게임성 탐색](01-게임성-탐색.md)

## 1. 확인된 조건

| 항목 | 조건 | 설계에 주는 의미 |
|---|---|---|
| 기기 | iPad 10세대, 학생 1인 1대 | A14 칩. 저폴리 3D는 충분하지만 그림자·후처리는 절제한다 |
| 브라우저 | Safari, Chrome 앱 | iPad의 Chrome도 WebKit 엔진이다. **Safari 기준으로 한 번만 검증**하면 된다 |
| 네트워크 | 무선 5G(와이파이), 21명이 동시에 유튜브를 봐도 지장 없음 | 실시간 위치 동기화(학생당 초당 수 KB 수준)에는 여유가 있다 |
| 동시 접속 | 학급 약 21명 | 한 방 21명 또는 모둠방(4~5명) 여러 개 |
| 조작 | 터치 전용 (키보드·마우스 없음 가정) | 가상 조이스틱, 카메라 드래그, 점프·다이브 버튼 |

## 2. 설계 기준

- 가로 화면 기준, 세로로 들면 회전 안내를 표시한다.
- 확대·스크롤·길게 누르기 메뉴 등 Safari 기본 제스처를 막는다.
- 화면 해상도 배율을 1.5 안팎으로 제한해 발열과 배터리 소모를 줄인다.
- 목표 프레임: 60fps (최소 30fps 유지).
- 설치 없이 URL로 접속한다. 필요하면 홈 화면에 추가해 전체 화면으로 실행한다.

## 3. 시제품 실측 (2026-09-28)

- iPad 10세대 Safari에서 [조작·맵 시제품](../prototype/README.md)이 **약 78fps**로 실행됨 (화질 "보통", 1인 플레이)
- Safari 확대·스크롤 간섭 없음
- 1인 기준 렌더링 여유가 충분하므로, 다른 플레이어 캐릭터 20명을 추가로 그리는 부담은 감당 가능할 것으로 예상 (멀티플레이 시험에서 확인 필요)
