# 26. 바람마을: 순풍 도약 (선택 도전)

## 교사 확인 기록

- 교사 보고(2026-10-02): **바람마을의 학습 내용은 교육과정을 충실하게 반영함.** 다만 게임성을 더 추가하기를 요청했다.
- 이 기록은 교사 보고이며 교실 검증이나 학습 효과의 증거가 아니다. 이번 수정은 학습 내용(압력·바람 방향·해풍과 육풍·안내문)을 바꾸지 않았다. [22](22-교육내용-점검.md)의 코드 기반 점검(문제 없음)과 같은 결론이다.

## 바뀐 것

- 왼쪽 **순풍 길**(고기압→저기압) 한가운데에 **바람 도약대**를 추가했다.
  - 경사로로 올라 높은 도약대(높이 3)에서 앞의 작은 섬(높이 1.5, 별 하나)으로 뛴다.
  - 틈은 바람 없이는 닿지 않고 순풍을 타면 닿게 맞췄다(시험 측정: 바람 없음 0.75~1.0m 모자람, 순풍 0.6~1.0m 여유). 높은 곳에서 내려 뛰어 공중에 오래 떠 있을수록 같은 바람이 더 크게 작용하므로 도약대를 높게 했다.
  - 못 닿으면 아래 길(높이 0)에 안전하게 내려앉는다. 떨어지지 않는다.
  - 도약대는 길 가운데에 있고 양옆 약 2.2m 통로는 비어 있어 기본 길이 막히지 않는다(시험으로 확인).
  - 역풍 길에는 두지 않았다. 순풍을 고른 결과가 새로운 도전 별에 닿는 보상이다([18](18-전체맵-게임성-분석.md) 개선 방향).
  - 안내판: "바람 도약대 (선택) / 순풍을 타고 멀리 뛰어 별까지! / 못 닿아도 길로 안전하게 내려와요".
- 별은 한 개 늘었다(진행 표시의 전체 별 수가 바뀜).
- 시험: `tests/windvillage.mjs`에 도약 시험 추가(순풍이면 섬·별, 바람 없으면 못 닿고 길로 내려앉음, 도약 위치 3가지, 도약대 옆 통로 2곳). 전체 `npm test` 통과.
- 공통 파일 변경: 없음 (`kit.js`·`wind.js` 미수정). 바람 계산과 안내문은 그대로다.

## 과학 범위와 모형 표시

- 바람의 방향과 세기(압력 기울기), 순풍·역풍 개념은 그대로다. "학생을 미는 힘은 게임 과장" 안내(입구 안내판)가 이 도약에도 적용된다. 실제 바람이 사람의 도약을 이렇게 크게 바꾸지는 않으므로 도약은 게임 장치다.

## 한계와 후속 후보

- 도약 성공/실패 경계가 1m 안팎이라 터치 조작에서 타이밍이 어려울 수 있다. 어렵다는 관찰이 나오면 틈을 줄인다(`islandZ`). 대신 바람 없이도 닿는 정도가 되지 않도록 시험이 보호한다.
- 역풍 길을 고른 학생이 이 도전을 못 한다. 반대쪽 이점(예: 역풍 쪽의 다른 선택 보상)은 만들지 않았다. 교실에서 "역풍 길은 손해만 본다"는 반응이 나오는지 본다.
- 후속 후보(미설계): ① 해안 구간을 한 방향 이동으로 정리해 낮에 건너면 순풍이 되게 함, ② 기류 발판(상승·하강)을 타서 닿는 높은 길, ③ 낮밤에 따라 열리는 해안 도전.

## 교실에서 볼 장면 ([12](12-교실-시험-관찰지.md)에 추가)

1. 학생이 순풍 길과 역풍 길 중 무엇을 고르는지, 바람 표시(깃발·화살표)를 보고 고르는지.
2. 도약대를 시도하는 학생의 비율, 몇 번 만에 성공하는지, 포기하는지.
3. "순풍이라서 더 멀리 갔다"고 말하는 학생이 있는지.
4. 도약대가 통로를 좁혀 혼잡을 만드는지(21명 방).
