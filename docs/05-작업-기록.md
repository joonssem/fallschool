### Claude 바람마을 검토 인수인계

- 교실 시험 관찰지는 [12번 문서](12-교실-시험-관찰지.md)로 번호 정리. 바람마을 제작은 11번, 미술 공방 학생 20명 관찰은 13번을 유지. 기존 11번 관찰지 파일명을 가리키는 링크는 검색에서 발견되지 않음.
- 바람마을 동적 안내판에 Apple SD Gothic Neo 글꼴과 폭에 따른 최소 22px 축소 적용을 확인. iPad 화면 확인은 별도.
- Claude 보고: 11개 맵 안내판 549줄 Windows 실측에서 잘리는 줄 없음. 봇 이동은 갈림길 순풍 3.9초/역풍 6.1초, 해안 한 번 횡단 순풍 2.0초/역풍 3.5초. 왕복 경로는 해당 측정에서 낮·밤 모두 12.14초. Codex가 재실측한 수치는 아님.
- 경로 변경은 보류. 학생이 H/L로 선택하는지, 낮밤별 한 번 횡단의 차이를 느끼는지를 먼저 관찰. 전체 왕복 시간을 줄이려고 기다리는 행동이 생기는지는 단정하지 않음.

### 색과 빛의 미술 공방 — 학생 20명 실제 체험

- 교사 보고: 학생 반응이 좋았고, 화면을 보며 서로 질문·답변하면서 진행. 생각을 선택으로 옮기고 선택 결과가 다음 사고·행동으로 이어짐. 먼저 통과한 학생이 친구를 돕는 경우도 발생. 교사는 결과적으로 만족.
- 같은 맵을 같은 학생에게 다시 진행하면 지루할 것 같다는 것은 교사의 예상이며 재진행 결과는 아님. 다른 반의 첫 체험으로 확대하는 방향을 제안. 관찰과 해석, 다른 반 안내 초안은 [13. 미술 공방 교실 관찰](13-미술공방-교실-관찰.md)에 기록.
- 학습 성취도·처음 보는 상황에 대한 적용·FPS·완주율은 측정하지 않음. 이번 기록은 사용자 제공 수업 관찰이며 직접 관찰·로그 분석은 아님.

### Codex 새 맵 제작

- 열한 번째 맵 **바람마을** 첫 버전 제작. 풍향계 입구·순풍/역풍 갈림길·기류 발판과 안전 계단·해풍/육풍 다리. 학생 아이디어 '아이엠가든 · 버블리'를 출발지에 표시. 새 맵 시험 52개, 전체 890개 통과. PC 표시 확인, iPad·실제 다인 교실은 남음. [11. 바람마을 제작](11-바람마을-제작.md).

- 통합 후 전기 회로 PC 화면 점검: 기본 시야에서 잘리는 현황판을 문 옆으로 낮추고, 전구를 우회하는 것으로 보이는 바닥 반환선을 전구 양쪽 별도 연결로 수정. 상세 확인·한계는 [10 문서](10-과학표현-협동-수정.md)의 'Codex 통합 후 화면 확인'에 기록. 전체 시험 835/835 통과(추가 바람 계산 25개 포함). 교사 패널은 브라우저 연결 문제로 화면 확인을 마치지 못함.

- Claude의 과학 표현·협동 구간·시작 화면 변경을 통합 검토: [10. 과학 표현·협동 구간 수정](10-과학표현-협동-수정.md). 새 맵 세 개의 수학·미술 분류와 테스트 명령을 함께 유지.
- 통합 시험 810/810 통과. PC 브라우저에서 10개 맵 목록·수학 분류·도형 맵 선택과 연습 시작을 확인. 시작 소개는 수학·미술도 포함하도록 '체험 코스'로 수정. 실제 Firebase·iPad 검증은 남음.

- 여덟 번째 맵 `pizza` 첫 버전 추가. 조각 발판으로 1/2·3/4·1 주문을 완성하고, 같은 크기의 피자 원으로 목표량·현재량을 비교. 과량 선택은 취소·초기화로 복구하며 탈락 없음.

  - 새 칸은 따로 보내서, 규칙 게시 전에도 기존 기록(완주 등)은 영향 없음

  - 확인한 사실: 표면 중력 10.44 m/s²(적도, 1기압 높이) ÷ 9.8 ≈ 1.07배, 평균 밀도 0.69 g/cm³(물보다 작음), 목성 다음으로 큼 → 예측 문 질문·보기·설명은 그대로 맞음
  - 고리 다리 난이도 차이 없음 (같은 봇으로 0.9배 18/40, 1.07배 18/40). 도전 별 섬 거리 8m → 6.5m (×1.07에서 보통 점프 5m, 점프 + 다이브 7.75m), 별 시뮬레이션 48/48
- **무게로 기우는 시소**: 올라탄 모든 학생의 위치로 기울기 계산 (혼자 약 22°, 둘 이상 약 54°). 한쪽에 여럿이 몰리면 확 기울어 떨어지고, 양쪽에 나눠 서면 수평. 데이터베이스 변경 없음. 점프 연구소 시소 두 개에 적용
  - 캐릭터끼리 부딪히는 기능은 하지 않기로 함 (길 막기·머리 밟고 벽 넘기·늦게 오는 위치 문제)
