### 참고: 작업 중 겪은 문제

- Claude Code의 자동 모드 안전 검사가 여러 번 응답하지 않아 명령 실행이 멈췄다. 자동 모드를 끄고(Shift+Tab) 진행하면 명령마다 허락을 묻는 대신 멈추지 않는다.
- 규칙을 채팅 화면에서 복사하면 긴 줄이 줄바꿈되어 "unterminated string literal" 오류가 났다. 규칙은 파일(메모장 또는 GitHub)에서 복사한다.
