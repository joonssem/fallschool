## 최신 구현 범위

### Claude 검토 후 후속 반영 상태

이 맵은 현재 [Claude 검토](34-새맵3개-검토.md)와 [Codex 전달](35-Codex-전달-새맵검토.md) 이후의 구현 상태로 확인한다.

- 세 정류장에 같은 앞으로·왼쪽·오른쪽 팔레트를 두고, 학생이 정답 순서를 미리 밟지 않도록 바꿨다. 실행 발판에는 선택한 명령이 아이콘 목록으로 나타나며 실행 중 현재 순서를 강조한다.
- 목표 좌표에 도착하면 명령 길이와 상관없이 성공하므로 같은 목적지에 닿는 다른 명령 조합도 허용한다. 배송 뒤에도 명령 지우기 발판을 이용해 재시도할 수 있다.
- 명령 발판은 두 줄로 나눠 의도하지 않은 입력 가능성을 줄였다. 목적지 건물은 로봇 정지점 뒤로 옮겼다.
- `tests/robotcity-walk.mjs`는 정류장 팔레트에서 실제로 걸어 명령을 입력·실행하고, 배송 성공·문 통과·초기화 후 재시도·다른 성공 조합을 확인한다. 이는 이동·규칙 검증이지 실제 입력 실수나 학습 효과의 증거가 아니다.
- 화면 가독성, 실제 PC/iPad 터치와 교실 관찰은 미확인이다. 학생이 버튼을 잘못 밟는 빈도는 수업에서 확인한다.

세 배송 정류장에서 동일한 앞으로·왼쪽·오른쪽 팔레트로 명령을 고른다. 실행 발판 뒤 로봇은 회전·이동을 순서대로 수행하며, 안내판에 명령 목록과 실행 중인 명령이 강조된다. 오배송 뒤 명령을 지워 바꿀 수 있고, 배송 성공 뒤에도 다시 시도할 수 있다. 목적지 건물은 로봇 정지점 뒤에 있다. 정밀 코딩 문법은 요구하지 않는다.

구간은 직선 배송 → 회전이 필요한 모퉁이 → 더 긴 공원 길로 바뀐다. 기본 배송은 명령 수 최적화 없이 가능하다. 도전 별은 선택이며 완주 조건에 포함되지 않는다. 학생별 상태라 다른 학생이 조작을 덮어쓰지 않는다. 탈락, 학생 간 밀치기·잡기, 필수 동시 협동은 없다. 체크포인트는 각 정류장에 있다.

아직 없는 기능은 개별 명령 한 칸 교체 UI, 반복 명령 블록, 최단 경로 도전이다. 다른 명령 조합 시험은 초기화 후 가능하다. 화면·실제 입력 오류·교실에서의 게임성은 미확인이다.

## 교육 표현·게임 규칙 범위

이 맵은 초등 수준의 명령 순서·방향 전환·실행 결과를 다루는 게임 모형이다. 실제 도시 배송 시스템, 자율주행, 최단 경로 알고리즘의 완전한 모사라고 표현하지 않는다. 반복 명령 블록이나 복수 해법 검증은 후속 구현 대상이다.

## 공통 파일 영향

새 독립 파일 `prototype/src/levels/robotcity.js`와 계산·실제 걸음 시험을 추가하고 공통 맵 등록·시험 묶음을 수정했다. 현재 작업 묶음에는 새 맵 세 개가 있어 선택 목록은 15개다. 공용 플레이어·맵 빌더·물리·협동·Firebase API는 변경하지 않았다. 명령 팔레트와 상태 표시는 이 맵 전용 구현이다.

## 확인 및 교실 관찰

자동 시험은 좌표·방향·단계별 경로, 실제 걸음 배송·문 통과, 초기화, 다른 성공 조합, 맵 등록을 검사한다. 이는 규칙·이동 검증이지 재미나 교육 효과의 증거가 아니다. 브라우저 화면, iPad 터치·가독성·FPS, 실제 교실 사용은 아직 확인하지 않았다.

교실에서는 학생이 실행 전에 다음 도착 위치를 예상하는지, 로봇의 실제 경로를 보고 명령을 고치는지, 배송 후 다른 성공 방법을 시도하는지, 발판 선택 줄에서 불필요하게 오가거나 입력을 잘못하는지 관찰한다. 먼저 끝난 학생이 친구에게 단순 정답을 주는지 경로를 설명하는지도 기록한다. 수업 뒤에는 “어떤 명령을 바꿨고, 로봇 경로에서 무엇을 보고 결정했나요?”를 묻는다. 첫 체험과 같은 반 재체험은 구분한다.

## 2026-10-06 연장: 정류장 4·5와 반복 명령 (Claude, 길이 약 131m → 약 206m)

- 근거: 교사 의견(맵 길이가 짧다), `AGENTS.md` 길이 기준(150~250m), 사용자 요청(200m 이상), 이 문서의 "아직 없는 기능: 반복 명령 블록, 최단 경로 도전". 계획은 [56](56-맵-길이-연장-계획.md) 3.2.

### 구간

| 정류장 | z | 새로 판단하는 것 | 명령 제한 |
|---|---|---|---|
| ④ 반복 배송 | -136 | 새 명령 **반복 ×3**. 앞으로 여섯 칸 + 오른쪽 회전 + 한 칸이라 반복 없이는 6개 이하로 닿지 않는다 | 6개 |
| ⑤ 도시 광장 배송 | -179 | 기본은 반복 없이 6개(앞으로 둘, 오른쪽, 앞으로 셋). **반복을 쓰면 5개**로 줄어 선택 별이 나타난다 | 8개 |

- 반복 ×3은 움직이지 않는 수정 명령이며 **바로 다음 명령에만** 적용된다(회전에 쓰면 세 번 회전). 안내판과 명령 목록(×3 아이콘)에 표시한다.
- ④의 문은 로봇이 더 멀리 가므로 더 멀리 있다(z -19). 정류장 4·5는 네 발판(앞으로·왼쪽·오른쪽·반복)을 **한 줄**로 두어 발판 사이를 지나다 다른 발판을 밟지 않게 했다(시험에서 대각선으로 걷다 왼쪽 발판을 밟는 문제를 발견해 고침).
- 별은 도시 광장 별(5개 이하 배송)과 결승 별을 합쳐 2개. 체크포인트 간격 45m 이하.
- 이번 연장에는 **배송 벨트**(폴 가이즈 참고 제안)를 넣지 않았다. 반복 명령 도입의 판단이 새로워서, 이동 장치는 교사 시험 뒤에 판단한다.
