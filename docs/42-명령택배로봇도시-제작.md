# 명령 택배 로봇 도시 제작

2026-10-02. [16. 새로운 맵 아이디어](16-새로운-맵-아이디어.md)의 다음 제작 후보를 구현했다. 새 맵 제작자인 Codex가 맡았다. [18. 전체 맵 게임성 분석](18-전체맵-게임성-분석.md)과 [19. 게임성 반영 기준](19-게임성-반영-기준.md)을 적용했다. 재미와 학습 효과는 아직 교실에서 확인하지 않았다.

## 첫 구현 범위

세 배송 정류장을 지나며 학생이 앞으로·좌회전·우회전 명령을 선택한다. 짧은 발판 줄은 입력 장치이고, 실행 발판을 밟으면 실제 로봇이 한 단계씩 움직인다. 주행 경로 표식과 현재 명령 수가 보이며, 배송에 실패하면 로봇이 도착한 위치를 확인하고 명령을 지워 다시 시도할 수 있다. 성공하면 배달 건물 색이 바뀌고 학생이 건널 길이 나타난다. 정밀 코딩 문법은 요구하지 않는다.

구간은 직선 배송 → 회전이 필요한 모퉁이 → 더 긴 공원 길로 바뀐다. 기본 배송은 명령 수 최적화 없이 가능하다. 도전 별은 선택이며 완주 조건에 포함되지 않는다. 학생별 상태라 다른 학생이 조작을 덮어쓰지 않는다. 탈락, 학생 간 밀치기·잡기, 필수 동시 협동은 없다. 체크포인트는 각 정류장에 있다.

현재 구간의 명령은 길이에 맞춘 짧은 발판 줄에서 선택한다. 잘못된 실행은 틀린 위치에 멈추므로 경로를 보고 명령 지우기 후 다시 선택할 수 있다. 개별 명령 한 칸만 교체하는 UI는 아직 없다. 반복 명령 블록·다중 경로 배송은 후속 후보이며 기본 완주를 막지 않는다.

## 19번 게임성 점검표

| 항목 | 첫 버전 설계·구현 |
|---|---|
| 핵심 재미 | 내가 고른 명령대로 배송 로봇이 실제 도시 길을 달리고 목적지에 도착한다. 교실 재미는 미확인. |
| 의미 있는 선택 | 이동·회전 명령을 짧게 선택한다. 회전이 필요한 구간에서 방향 선택이 목적지에 영향을 준다. |
| 즉시 결과 | 실행 중 로봇 위치·방향과 지나온 경로 표식이 순서대로 나타난다. |
| 다음 행동·성취 | 배송 성공 시 건물이 표시되고 다음 통로가 놓인다. 단순 정답 문으로 끝내지 않는다. |
| 구간 변화 | 직선 → 한 번 회전 → 복수 이동과 회전. 명령 반복 횟수만 늘리지 않는다. |
| 재시도 부담 | 학생을 떨어뜨리지 않는다. 잘못 도착해도 가까운 정류장에서 명령 초기화 후 실행 가능. 입력은 발판 줄이라 터치 오입력 관찰이 필요하다. |
| 기본 완주·선택 도전 | 배송 성공이 기본 조건. 도전 별과 최단 명령은 선택 활동이며 우회 가능하다. |
| 친구와의 연결 | 독립 상태를 유지하면서 경로를 보고 자발적으로 설명할 수 있다. 강제 협동이나 대기 역할은 없다. |
| 재체험 용도 | 첫 체험용. 현재 같은 목표의 재체험은 다른 명령 조합 찾기와 실행 안정성 연습이며, 시드 변형은 아직 없다. |
| 근거·관찰 | 코드와 규칙 시험으로 배송 좌표·회전·경로 표시 조건을 확인한다. 교사 보고 및 학습 효과 자료는 없다. |

## 교육 표현·게임 규칙 범위

이 맵은 초등 수준의 명령 순서·방향 전환·실행 결과를 다루는 게임 모형이다. 실제 도시 배송 시스템, 자율주행, 최단 경로 알고리즘의 완전한 모사라고 표현하지 않는다. 반복 명령 블록이나 복수 해법 검증은 후속 구현 대상이다.

## 공통 파일 영향

새 독립 파일 `prototype/src/levels/robotcity.js`와 전용 시험 `prototype/tests/robotcity.mjs`를 추가하고, 공통 맵 선택 등록 `prototype/src/levels/index.js` 및 시험 묶음 `prototype/package.json`을 수정했다. `index.js` 변경으로 선택 화면에 13번째 맵이 추가된다. 기존 맵 ID·구현·맵 빌더 인터페이스, `kit.js`, 물리·협동·Firebase 코드는 변경하지 않았다. 기존 선택 목록을 길이로 고정 가정하는 외부 코드가 있다면 등록 수 증가의 호환성을 확인해야 한다.

## 확인 및 교실 관찰

자동 시험은 좌표·방향·단계별 경로·맵 등록을 검사한다. 이는 규칙과 이동 계산 검증이며 재미나 교육 효과의 증거가 아니다. 브라우저 화면, iPad 터치·가독성·FPS, 실제 교실 사용은 아직 확인하지 않았다.

교실에서는 학생이 실행 전에 다음 도착 위치를 예상하는지, 로봇의 실제 경로를 보고 명령을 고치는지, 배송 후 다른 성공 방법을 시도하는지, 발판 선택 줄에서 불필요하게 오가거나 입력을 잘못하는지 관찰한다. 먼저 끝난 학생이 친구에게 단순 정답을 주는지 경로를 설명하는지도 기록한다. 수업 뒤에는 “어떤 명령을 바꿨고, 로봇 경로에서 무엇을 보고 결정했나요?”를 묻는다. 첫 체험과 같은 반 재체험은 구분한다.
