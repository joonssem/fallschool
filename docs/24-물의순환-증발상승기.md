# 24. 물의 순환: 증발 상승기 (선택 지름길)

- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.**

## 바뀐 것

- 증발 구간(시작 지점 양옆)에 **상승기 두 대**를 추가했다. 계단(기본 길)은 그대로다.
  - 동쪽 **햇빛 아래 상승기**: 오르는 데 3초(주기 9초). 노란 승강장, 위로 올라가는 희미한 수증기 점이 많고 빠르다.
  - 서쪽 **그늘 상승기**: 오르는 데 8초(주기 19.5초). 회색 승강장, 구름 장식, 수증기 점이 적고 느리다.
  - 두 상승기는 구름 쪽 계단 끝 발판(구름 도착 지점)으로 이어지고, 위 통로 옆에 도전 별이 하나씩 있다(둘 다 짧은 도약으로 닿음).
  - 상승기 위치는 시간 `t`만으로 정해져 모든 화면에서 같다. 학생이 서 있는 곳과 무관하므로 서로 방해하거나 막지 않는다.
  - 상승기 위의 신호등: 초록 = 아래에 와 있어 탈 수 있음, 빨강 = 움직이는 중.
- 시험: `tests/water-lift.mjs` 추가(80건) 및 `package.json`의 `npm test`에 등록. 두 상승기 모두 구름 쪽 계단 끝에 닿고 별을 얻으며, 같은 시각에 출발하면 햇빛 쪽이 먼저 도착한다. 평균 소요(봇): 햇빛 14초, 그늘 26초(기다림 포함).
- 공통 파일(`kit.js`) 변경 없음. 맵 인터페이스 변경 없음.

## 과학 범위와 모형 표시

- 표현하는 것: 따뜻할수록 증발이 활발하다는 **방향**. 안내판: "따뜻하면 증발이 활발해요 / 덜 따뜻하면 증발이 느려요 / 게임에서는 더 빨라요".
- 쓰지 않은 것: 증발 속도 수치, 실제 상승 속도. 상승기는 게임 장치이며 수증기 점은 "보이지 않는 기체"를 희미한 점으로 표시한 것이다(기존 수증기 안내와 동일).

## 한계와 미결정

- **상승기가 계단보다 오히려 오래 걸릴 수 있다**: 대기 포함 평균 14초(햇빛)·26초(그늘)이고, 계단은 짧게 걸을 수 있다 `[추론: 계단 소요는 이번에 측정하지 못했다]`. 그래서 상승기를 시간 절약이 아니라 **체험·비교와 별 보상**을 위한 선택으로 설계했다. 별과 비교 체험이 학생에게 충분한 이유인지는 교실에서 봐야 한다. 필요하면 상승기 위치·주기 조정이나 계단과의 차별 보상을 고려한다.
- 햇빛 쪽이 빠르다는 결론은 두 번 타 보면 알 수 있다. 판단이 필요한지(그냥 아무 데나 타는지)는 관찰 항목이다.
- 상승기는 학생이 아니라 시간에 따라 움직이므로 "학생이 서 있는 곳이 속도를 정한다"는 구조가 아니다. 실제 증발이 온도에 따라 달라지는 모습을 두 장치의 비교로 보여 주는 모형이다.
- 4번(공용 장치 추출)과 지표수·지하수 갈림길의 선택 의미 추가는 하지 않았다.

## 근거 구분

- **코드·시험**: 두 상승기가 구름까지 도달, 별 획득, 같은 시각 출발 시 햇빛이 먼저 도착(규칙·이동 검증, 시드 2개·출발 시각 8개).
- **미확인**: 화면 가독성(안내판 글자 크기, 신호등·점이 보이는지), 카메라에서 상승기가 눈에 띄는지, 학생 반응.

4. 별을 위해 상승기를 타는 학생이 있는가.
