# 27. 인체 대탐험: 산소 배달 (선택)

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: [14](14-기존맵-수정후보.md) 6번, [18](18-전체맵-게임성-분석.md)(인체: 전달 대상 선택 → 세포 반응), [19](19-게임성-반영-기준.md)
- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.**

## 바뀐 것

- 모세혈관 바닥 서쪽 가장자리(`x -7.5`)에 **발판 3개**(근육·뇌·위)를 놓고, 서쪽 바깥(`x -15`)에 해당 장기 모형을 띄웠다.
  - 발판에 서면 파란 산소를 그 장기에 배달한다. 장기가 반짝이며 커졌다 돌아오고, 회색 이산화탄소 알갱이가 장기에서 폐 쪽(뒤쪽)으로 흘러간다.
  - 안내판이 "산소 배달 n / 3 곳"을 보여 주고, 세 곳 모두에 전달하면 "온몸에 산소 전달 완료! 모든 세포가 산소를 써요"로 바뀐다.
  - 발판마다 설명이 다르다(근육은 에너지·힘, 뇌·위는 세포도 산소가 필요). 어느 장기를 고르든 과학은 같다.
- 선택 활동이다. 안내판에 "안 해도 돼요"를 적었고 기본 길(모세혈관→근육 발판)과 떨어져 있다. 상태는 학생별이다.
- 심장·혈관 흐름은 바꾸지 않았다. 심방→심실 순서 요구와 판막 협동 표현도 추가하지 않았다(`docs/14` 하지 말 것 준수). 혈관 종류(동맥·정맥)와 방향 그림도 건드리지 않았다.
- 시험(`tests/body-water.mjs body`): 기본 길을 지나가도 발판이 눌리지 않음, 세 발판 차례 배달, 세 곳 전달됨, 진행 초기화 시 처음 상태(시드 3개). 기존 인체 시험 210건 그대로. 전체 `npm test` 통과.
- 공통 파일 변경: 없음. `variants.js`의 `dynamicSign`을 가져다 썼다.

## 과학 범위

- 표현하는 것: 산소는 몸의 모든 세포가 쓰고, 쓰고 남은 이산화탄소는 혈액이 폐로 실어 간다. 기존 안내문("산소는 온몸으로", "이산화탄소는 폐로")과 같은 내용이다.
- 쓰지 않은 것: 세포 호흡의 화학식, 혈액이 장기마다 나뉘는 비율, 정맥으로의 회수 경로 설명. 장기 모형은 단순 도형이다.
- "갈래 선택(근육 쪽/폐 쪽)"으로 구현하지 않았다. 그렇게 하면 산소가 폐로 가는 길을 학생이 틀릴 수 있는 구조가 되어 혈관 종류·방향을 잘못 읽게 할 위험이 있었다. 대신 장기를 고르는 배달로 바꿨다.

## docs/19 점검표

| 항목 | 기록 |
|---|---|
| 핵심 재미 | 산소를 장기에 배달하고 장기가 반응하는 것을 보는 작은 임무 |
| 의미 있는 선택 | 세 장기 중 어디에 줄지. 선택마다 다른 장기가 반짝이고 설명이 다르다. 정답·오답은 없다(과학 판단이 아니라 탐색) |
| 즉시 결과 | 장기 반짝임·커짐, 이산화탄소 알갱이, 진행 표시 `[설계 의도, 화면 미확인]` |
| 다음 행동·성취 | 3 / 3 전달 시 "온몸에 산소 전달 완료" 표시. 별·문 같은 길에 연결되는 보상은 없다 |
| 구간 변화 | 모세혈관 구간에 선택이 생겼다. 폐·심장·동맥 구간은 바뀌지 않았다. 갈림길 판단은 이번에 넣지 않았다 |
| 재시도 부담 | 떨어지거나 오답이 없다. 같은 발판을 다시 밟아도 된다 |
| 기본 완주·선택 도전 | 기본 길은 그대로. 안내판에 선택 표시 |
| 친구와의 연결 | 직접 협동 없음. "나는 뇌에 줬어" 같은 대화 `[기대, 미확인]` |
| 재체험 용도 | 세 곳을 다 주면 새 판단이 없다. 첫 체험용이다. 성취 보상이 약해 재체험 동기는 낮다 |
| 근거·관찰 | 코드·시험(규칙·이동). 재미는 미확인 |

## 한계와 후속 후보

- 세 곳 전달 후 보상이 표시뿐이라 "다음 행동"과의 연결이 약하다. 관찰에서 "해도 그만"이라는 반응이 나오면 별·문 열림 같은 보상이나 장기별 짧은 임무로 확장한다.
- 장기 모형과 안내판의 위치가 카메라에서 보이는지, 모세혈관 안내판(`x -11`)과 겹치지 않는지는 화면 확인 전이다.
- `docs/14` 6번의 "판막" 부분(두 발판에 서기 단독 통과 가능)은 바꾸지 않았다.

## 교실에서 볼 장면

1. 배달 발판을 밟는 학생의 비율, 어느 장기부터 고르는지, 세 곳 모두 하는지.
2. 장기가 반짝이고 알갱이가 흐르는 것을 보고 설명을 읽는지.
3. "산소는 근육에만 가는 게 아니다"를 자기 말로 하는지.
4. 안내판·장기 모형 때문에 시야나 이동이 불편한 학생이 있는지.
