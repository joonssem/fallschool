# 15. 산과 염기 안전 시험 장치 — 구현 요청서

2026-10-01. [14번 수정 후보](14-기존맵-수정후보.md)의 첫 작업을 구체화한다. 사용자 선택에 따라 **Claude가 구현, Codex가 요청서·검증 준비**를 담당한다. 이 문서 작성 시점에는 구현하지 않았다.

## 학생이 할 일

1. 용액 발판에서 식초 또는 비눗물을 선택한다.
2. 종이 발판에서 푸른 종이 또는 붉은 종이를 선택한다. 선택 순서는 자유다.
3. 두 선택이 갖춰지면 **넣기 전 → 넣은 뒤** 도식·색 이름·짧은 설명이 즉시 바뀐다.
4. 선택을 바꾸며 네 조합을 비교하고, 기존 리트머스 길에서 색을 고른다.

| 용액 | 시작 종이 | 결과 | 설명 |
|---|---|---|---|
| 식초(산성) | 푸른 종이 | 붉은색 | 푸른 종이가 붉게 변함 |
| 식초(산성) | 붉은 종이 | 붉은색 | 붉은 종이는 그대로 |
| 이 실험의 비눗물(염기성) | 붉은 종이 | 푸른색 | 붉은 종이가 푸르게 변함 |
| 이 실험의 비눗물(염기성) | 푸른 종이 | 푸른색 | 푸른 종이는 그대로 |

색을 그림과 이름으로 함께 표시한다. 색이 변하지 않는 경우에도 결과를 표시한다. 실제 제품마다 성질이 다를 수 있으므로 모든 비눗물의 세기를 단정하거나 수치를 표시하지 않는다. 용액이 종이를 녹인다는 설명은 넣지 않는다.

## 배치와 상태

- 식초 앞 체크포인트 `cpA`는 `(0, 1.5, -40)`, 입구 발판은 `z=-38~-44`이다. 비눗물 앞 `cpB`는 `(0, 1.5, -60)`, 입구 발판은 `z=-58~-64`이다. 첫 타일 중심은 각각 `-45.7`, `-65.7`이다.
- 각 입구의 안전한 옆 공간에 동일한 시험대를 두는 안을 우선 검토한다. 현재 식초 안내판은 왼쪽, 비눗물 안내판은 오른쪽이므로 시험대는 반대편이 적합하다. 필요하면 **입구 깊이 안에서만** 옆 받침을 추가한다. 타일 구간을 따라 옆길을 만들지 않는다.
- 용액 둘·종이 둘, 총 네 선택 발판. 확정 버튼·시험 정답 문·사용 의무·추락 오답은 없다. 기존 길을 가는 학생의 가운데 통로를 막지 않는다.
- 종이를 골랐으나 용액이 없으면 시작 색만 보여 준다. 두 선택 전에는 결과를 추측해서 채우지 않는다.
- 상태는 학생별·시험대별로 저장한다. 다른 학생의 위치·선택·`triggerTile()`로 내 시험 결과를 바꾸지 않는다.
- 시작·새 경기·처음부터에서 선택과 발판 점유 상태를 초기화한다. 결과 그림은 별도 상호작용 없이 즉시 갱신한다.
- 기존 타일 배치 시드·안전 색·녹음과 공유·`noHelp`·예측 문·체크포인트·도전 별을 유지한다.

## 변경 범위

- 우선 `acid.js` 안의 작은 장치로 구현한다. 과학 결과 판정은 네 조합을 한 곳에서 계산하고 도식·설명도 같은 결과를 사용한다.
- 현재 Codex는 `kit.js` 수정 작업을 하지 않는다. 이번 단계는 `kit.js`, `main.js`, Firebase 필드·규칙 변경 없이 구현할 수 있다.
- 미술 공방의 확정·문 열림 구조 전체를 먼저 추출하지 않는다. 두 번째 적용 대상이 구체화된 뒤 공용 모듈을 판단한다.

## 완료 기준

게임성 기준도 [19번 점검표](19-게임성-반영-기준.md)에 따라 기록한다. 실험 결과가 실제 타일 선택에 도움이 되는지, 같은 발판을 불필요하게 왕복하는지, 시험대가 가운데 이동이나 친구 설명을 방해하는지 확인한다. 시험 사용은 선택으로 유지한다. 안전 실험이 새 확정 문으로 바뀌지 않도록 한다. 재미·선택 이유는 코드 시험과 구분해 교실 관찰 대상으로 남긴다.

| 검증 | 확인할 것 |
|---|---|
| 네 조합 | 기대표와 실제 색·색 이름·설명이 일치 |
| 선택 순서·변경 | 용액 먼저·종이 먼저 모두 가능, 결과가 즉시 갱신 |
| 개인 상태 | 다른 학생 위치·타일 공유가 시험 선택에 영향 없음 |
| 초기화 | 새 경기·처음부터 후 미선택 상태 |
| 기존 규칙 | 동일 시드의 타일 안전 색·배치와 `noHelp` 유지 |
| 이동 | 시험대를 이용하지 않아도 기존 길 통과, 시험대 왕복 가능, 타일 구간 우회 없음 |
| PC 화면 | 두 시험대의 시작·결과 도식, 선택 표지·안내판 겹침·가운데 통로 확인 |
| 실기 | iPad 가독성·터치와 학생의 선택 이유는 교실 관찰 대상으로 기록 |

시험은 새 장치의 판단·상태·이동을 확인하고 전체 `npm test`를 실행한다. 자동 시험을 학습 효과 검증으로 쓰지 않는다.
