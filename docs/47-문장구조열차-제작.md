# 47. 문장 구조 열차 — 첫 버전

- 작성일: 2026-10-05. 새 맵 제작: Codex.
- 근거: [16. 새 맵 아이디어](16-새로운-맵-아이디어.md), [18. 게임성 분석](18-전체맵-게임성-분석.md), [19. 반영 기준](19-게임성-반영-기준.md).
- 상태: 코드·자동 이동 시험·PC 출발 화면 확인 완료. 교실·iPad 화면, 학생의 문장 이해와 실제 재미는 미확인. 앞선 자석 항구의 교실 관찰 결과는 아직 받지 못했으므로 두 맵의 난이도를 비교·확정하지 않는다.

## 플레이와 국어 범위

학생은 첫 갈림길에서 숲 또는 바다 길을 직접 걷는다. 선택한 풍경과 열차 색이 바뀌고, `기차는 숲으로 갔어요.` 또는 `기차는 바다로 갔어요.`가 보인다. 다음 역에서는 친구 또는 편지 길을 걸어 `그곳에서 친구를 만났어요.` 또는 `그곳에서 편지를 찾았어요.`를 고른다. 선택한 승객·편지가 열차 위에 나타나고 열차가 도착역으로 들어오며, 두 문장이 나란히 보인다. 네 조합 모두 자연스럽고 완주할 수 있다. 다른 길은 이전 갈림길로 돌아가 다시 고를 수 있다.

첫 버전은 장소를 나타내는 `숲으로/바다로`의 조사 형태와 앞 문장의 장소를 받는 `그곳에서`를 고정된 문장 안에서 경험한다. 자유 작문이나 한국어의 모든 조사·연결 표현을 채점하지 않는다. 열린 문장을 기계적으로 정오 판정하지 않고, 조합을 네 개의 미리 검토한 문장으로 제한했다. 이야기의 원인·결과 관계를 가르치는 맵이라고 주장하지 않는다.

## docs/19 게임성 점검표

| 항목 | 기록 |
|---|---|
| 핵심 재미 | 직접 고른 두 갈래 여행이 눈앞의 풍경·열차·이야기를 바꾼다 |
| 의미 있는 선택 | 숲/바다 목적지와 친구/편지 사건을 각각 길로 고른다. 네 결말이 다르다 |
| 즉시 결과 | 경로 도착 발판에서 다른 풍경이 사라지고 선택 장면·열차 색 또는 사건 물체가 나타난다 |
| 다음 행동·성취 | 첫 선택을 보고 다음 역에서 사건을 고른 뒤, 도착역에서 자신이 만든 두 문장과 들어오는 열차를 확인한다 |
| 구간 변화 | 장소 선택 뒤에는 `그곳에서` 일어난 사건을 고른다. 같은 답을 반복 요구하지 않는다 |
| 재시도 부담 | 네 조합 모두 통과한다. 넓은 경로, 가운데 체크포인트, 이전 갈림길 재선택을 둔다 |
| 기본 완주·선택 도전 | 어느 두 갈래를 골라도 완주한다. 별 섬은 옆으로 뛰어야 하는 선택 도전이다 |
| 친구와의 연결 | 서로 다른 이야기와 경로를 설명할 여지는 있다. 필수 동시 조작은 없다. 실제 대화는 미확인이다 |
| 재체험 용도 | 첫 체험에서 네 조합의 이야기를 비교할 수 있다. 조합을 모두 본 뒤의 장기 반복성은 주장하지 않는다 |
| 근거·관찰 | 자동 시험은 네 경로의 이동·상태·초기화만 검증한다. 국어 학습·즐거움은 교실 확인 전이다 |

자석 항구의 `선택 → 물체가 다리로 이동 → 건너기`와 달리, 이 맵은 두 번의 길 선택 자체가 문장의 장소와 사건이 된다. 문을 열기 위한 정답 퀴즈는 없다. 기차의 레일 이동은 장면 보상이며 학생이 탑승하는 물리 장치는 아니다.

## 구현·검증

- `prototype/src/levels/sentencetrain.js`: 두 갈림길, 풍경·열차·도착 문장, 체크포인트, 선택 별. 개인 화면 상태로 다른 학생의 선택이 내 이야기를 바꾸지 않는다.
- `prototype/src/levels/index.js`: `sentencetrain`을 국어 맵으로 등록하고 국어 분류를 추가. 기존 맵 ID와 방 설정 형식은 유지한다.
- `prototype/tests/sentencetrain.mjs`: 등록, 상태·화면 결과, 재선택, 초기화, 네 조합의 실제 이동 완주를 검사한다. 14건 통과. 맵 메타데이터 60건 통과.
- PC Chrome 출발 화면에서 중앙 제목판이 갈림길 안내를 가려 양옆으로 옮겼다. 수정 후 숲·바다 갈림길과 안내판이 보이는 출발 화면을 다시 확인했다. 뒤 장면과 iPad 실기 화면은 미확인이다.
- 공통 `kit.js`, 물리, 플레이어 입력, Firebase 규칙은 변경하지 않았다. 기존 시험을 포함한 전체 `npm test`가 통과했다.

## 수업에서 볼 장면

1. 학생이 길 색만 보고 고르는지, 장소·사건을 말로 예측하고 고르는지.
2. `숲으로/바다로`의 형태와 `그곳에서`가 앞의 장소를 가리킨다는 점을 자신의 이야기로 설명하는지.
3. 다른 조합을 보기 위해 스스로 돌아가 재선택하는지, 넓은 갈림길에서 터치 오입력이나 반복 낙하가 있는지.
4. 완성 문장판과 열차 보상을 실제로 멈춰 보고 친구에게 설명하는지.
5. 모든 조합을 경험한 뒤에도 탐험할 이유가 있는지. 첫 체험 만족과 재체험 가치를 분리해 기록한다.
