# 23. 거대 실험실: 공기 실험대 (선택 도전)

- 작성일: 2026-10-02, 담당: Claude (기존 맵 수정). 근거: [14. 수정 후보](14-기존맵-수정후보.md) 2번, [18](18-전체맵-게임성-분석.md), [19](19-게임성-반영-기준.md), [22. 교육 내용 점검](22-교육내용-점검.md) G1·G2
- 상태: **코드 구현·규칙 시험 완료. 화면(PC·iPad)과 교실 반응은 미확인.**

## 바뀐 것

- 피스톤 구간 입구 옆(`x 7~15, z -37~-42`)에 **공기 실험대**를 추가했다.
  - 발판 3개(약하게·보통·세게)를 밟으면 같은 개수의 알갱이가 든 주사기 도식의 피스톤이 움직이고 부피가 12·9·6칸으로 바뀐다(알갱이 간격이 좁아진다).
  - 문 앞 안내판의 **목표 부피**(판마다 시드로 12·9·6 중 하나)와 같아지면 문이 올라가 별 발판으로 갈 수 있다. 도식의 붉은 고리가 목표 눈금이다.
  - 학생이 보는 것은 칸 수이고, 어느 힘이 몇 칸인지는 눌러 보며 알아낸다.
- 구간 이름 `액체 높이 실험` → `부력과 뜨는 발판`, 안내판 제목 `액체 높이` → `부력` (docs/22 G1). 진행 기록은 구간 이름을 문자열로 보여 주므로 이전 기록이 있으면 옛 이름이 남을 수 있다 `[추론]`.
- 시험: `tests/giantlab.mjs`에 실험대 검사 추가(시드 6개). 전체 `npm test` 통과.
- 공통 파일 변경: **없음** (`kit.js` 미수정). `variants.js`의 `dynamicSign`·`rngFor`·`pick`을 가져다 썼다. 기존 맵 인터페이스는 그대로이고 `level.airBench`(시험용)와 `resetProgress` 덮어쓰기만 이 맵에 추가했다.

## 과학 범위와 모형 표시

- 보여 주는 것: 같은 양의 공기를 더 세게 누르면 차지하는 공간(부피)이 더 줄어든다.
- 쓰지 않은 것: 압력·부피의 식, 입자 수준 설명, 실제 힘의 크기. 수치는 `칸 (모형)`으로 표시했다. 알갱이는 개수가 그대로임을 보이는 그림이다.

## docs/19 점검표

| 항목 | 기록 |

| 핵심 재미 | 힘을 골라 주사기를 눌러 보고, 목표 부피를 맞춰 문을 여는 실험 |

| 즉시 결과 | 피스톤이 움직이고 칸 수 표시와 발판 색이 바뀐다. 읽기 전에 알갱이 간격으로 알아볼 수 있다 `[설계 의도, 화면 미확인]` |
| 다음 행동·성취 | 목표와 같으면 문이 올라가 별 발판으로 간다 |

| 재시도 부담 | 발판은 몇 번이든 다시 밟을 수 있고 틀려도 떨어지지 않는다. 문으로 가는 길은 발판 옆이라 지나가도 눌리지 않는다(시험으로 확인) |

## 한계와 결정 사항

- 목표가 3개뿐이라 모든 발판을 눌러 보면 곧 맞힌다. 이것이 탐색 중심의 학습인지 단순 시도인지는 교실에서 봐야 한다.
- [19](19-게임성-반영-기준.md) 표의 "피스톤 높이를 이동에 활용"과 달리, 안전한 선택 도전(문 열기)으로 구현했다. 피스톤 높이를 필수 이동에 쓰면 선택이 완주 조건이 되기 때문이다. 후속으로 피스톤 발판을 높이 변화로 연결하는 것은 관찰 뒤 검토한다.
- 같은 맵이어도 학생별 상태라 한 학생의 선택이 다른 화면에 보이지 않는다(미술 공방과 동일).
- 다음 후보: 부력 구간(물체와 물의 관계를 학생이 바꾸는 활동). 아직 설계하지 않았다.

## 근거 구분

- **코드·시험**: 문은 선택 전 닫혀 있고, 틀린 힘에서 닫혀 있고, 맞는 힘에서 열려 별을 얻으며, 진행 초기화로 처음 상태가 된다(시드 6개, 규칙·이동 검증).
- **미확인**: PC·iPad 화면의 글자 크기·도식 가독성, 도식 위치(카메라에서 보이는지), 교실 반응.

## 교실에서 볼 장면 ([12](12-교실-시험-관찰지.md) 관찰지에 추가)

1. 발판을 누른 뒤 피스톤과 알갱이를 보는가, 칸 수 글자를 읽는가.
2. 세 발판을 모두 눌러 보는가, 하나만 누르고 마는가.
3. 목표를 맞힌 학생이 "세게 누르면 부피가 줄어든다"를 자기 말로 설명하는가.
4. 실험대를 아예 지나치는 학생이 있는가(괜찮음). 있다면 안내판이 선택 활동임을 알려 주었는가.
